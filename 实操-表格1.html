本次课定位与目标

表格题与文字题最大的不同是：结果可以被精确校验。文字题错了还能靠排版观感拿点分，表格题只要一个引用写错，整列数字全错，评审点一个都不给。所以这一次课的重点不是「会做」，而是「每一步都能说出为什么」。

学完这 4 小节，你要能做到

  • 工作簿：会增删改移工作表、设标签颜色、冻结窗格，能设打印区域、顶端标题行、缩放与页脚页码
  • 格式：会用自定义格式（¥#,##0.00、yyyy年m月d日）、会保留前导零、会用数据有效性做下拉、会用条件格式标出异常值
  • 引用：能分清相对/绝对/混合引用（$ 的位置决定一切），会跨表引用、三维引用、定义名称
  • 函数：会用 SUM/AVERAGE/MAX/MIN/COUNT/COUNTA/ROUND/INT/MOD/ABS 与 IF/IFS/AND/OR 嵌套

💡 为什么这样排

按「表的结构 → 表的样子 → 表的关系 → 表的计算」推进：先把工作簿和工作表管好（打印是考试必考的小分点），再让数据看得清（格式与条件格式），再理解引用这个核心机制，最后进入函数。引用没搞懂就学函数，是表格题失分的第一大原因。

本小节必须掌握的知识点

例 4-1

建工作簿：4 张工作表 + 标签颜色 + 列宽行高 + 冻结首行

工作表管理标签颜色冻结窗格 14 分钟
题目要求
  1. 新建工作簿，保存为 学号-姓名-练习4-1.xlsx。
  2. 将 Sheet1 重命名为「销售明细」，再插入 2 张工作表，分别命名为「汇总」「参数」。
  3. 在「销售明细」中录入素材数据（12 条记录，含表头）。
  4. 列宽：A 8、B 12、C 10、D 10、E 12；行高：第 1 行 24，其余 20。
  5. 冻结首行（滚动时表头始终可见）。
  6. 把「汇总」移动到「参数」之前，并将「销售明细」标签设为红色。
  7. 在「参数」表 B1 输入「税率」、B2 输入 0.13。
  8. 保存。
录入素材
表头：日期 | 产品 | 数量 | 单价 | 金额
记录示例：2026-09-01 | 笔记本 | 12 | 4580 |
共 12 条，日期从 2026-09-01 起按天递增，产品在笔记本/台式机/显示器/键盘中轮换。
解题步骤
  1. 新建并立即保存。Ctrl+N 新建 → F12 另存为 → 文件名 学号-姓名-练习4-1.xlsx → 文件类型选「Excel 工作簿(*.xlsx)」。
    先存再填，是防断电、防误关的第一习惯。
  2. 重命名 Sheet1。双击工作表标签「Sheet1」→ 标签变可编辑状态 → 输入「销售明细」→ Enter。
  3. 插入两张表。点标签栏右侧的「+」号两次（或右键任意标签 →「插入工作表」）→ 分别双击改名为「汇总」「参数」。
  4. 录入数据。点 A1 开始录入，Tab 向右、Enter 向下；Alt+Enter 可在单元格内换行。
    日期直接输 2026-9-1，系统会自动识别为日期；不要输 2026.9.1（会变文本）。
  5. 设列宽。选中 A 列列标 → 右键 →「列宽」→ 输入 8 → 确定；B 列 12、C 列 10、D 列 10、E 列 12，逐列设置。
    想快速自适应可双击列标右边界，但题目给数值就必须用「列宽」对话框。
  6. 设行高。选中第 1 行行号 → 右键 →「行高」→ 24；再选中第 2~13 行 → 行高 20。
  7. 冻结首行。「视图」→「冻结窗格」→「冻结首行」。
    验证：向下滚动，第 1 行不动即为成功。
  8. 移动工作表。右键「汇总」标签 →「移动或复制」→ 在「下列选定工作表之前」选「参数」→ 不勾「建立副本」→ 确定。
    （拖动标签也能移，但跨位置远时容易拖错。）
  9. 设标签颜色。右键「销售明细」标签 →「工作表标签颜色」→ 选红色。
  10. 填参数表。切到「参数」表 → B1 输入「税率」→ B2 输入 0.13。
  11. 保存。Ctrl+S。
采分点4 张工作表名称完全一致 · 工作表顺序为 销售明细 / 汇总 / 参数 · 列宽 5 项与行高 2 项数值正确 · 已冻结首行 · 标签颜色为红色 · 参数表 B2 = 0.13 · 文件为 .xlsx

易错提醒

  • 另存为时选了「.xls」：部分函数与格式不受支持，且题目要求 xlsx 时会判格式错。
  • 「冻结首行」点成「冻结首列」：横着滚动没问题，竖着滚动表头就跑了。
  • 移动工作表时勾了「建立副本」：多出一张重复表，表数量不对。
  • 日期输成 2026.9.1 或 2026/9/1 文本：后续日期函数无法计算。
  • 直接拖列标边界调宽度：数值不可能正好是 8/12/10/10/12。

工作组的用法

按住 Ctrl 点多个工作表标签，标签变白即形成「工作组」，此时在一个表里输入/设置格式，所有选中的表同步生效。适合批量建同样表头。用完记得右键 →「取消成组工作表」，否则会误改其他表。

例 4-2

打印设置：打印区域 + 顶端标题行 + 1 页宽 + 页脚「第 X 页 共 Y 页」

打印区域顶端标题行缩放页脚 14 分钟
题目要求
  1. 打开素材（60 行销售数据，A1:F60）。
  2. 设置打印区域为 A1:F60。
  3. 设置顶端标题行为第 1 行（使每页都有表头）。
  4. 缩放方式设为「调整为 1 页宽」（高度不限）。
  5. 纸张 A4 横向，页边距上下左右均 1.5 厘米。
  6. 页脚居中显示「第 X 页 共 Y 页」，使用页码与总页数域。
  7. 进入打印预览确认共几页、每页是否都有表头。
  8. 保存为 学号-姓名-练习4-2.xlsx。
解题步骤
  1. 打开素材，确认数据范围为 A1:F60。
  2. 设打印区域。选中 A1:F60 →「页面布局」→「打印区域」→「设置打印区域」。设定后区域外会出现灰色虚线。
  3. 设顶端标题行。「页面布局」→「打印标题」→ 在「顶端标题行」输入框里点右侧的折叠按钮 → 用鼠标点第 1 行的行号 → 框内显示 $1:$1 → 确定。
  4. 设缩放。同一「页面设置」对话框 →「页面」选项卡 → 缩放选「调整为」→ 宽 1 页、高留空（或填 0，表示自动）。
  5. 设纸张与方向。同对话框 → 纸张大小「A4」→ 方向「横向」。
  6. 设页边距。切到「页边距」选项卡 → 上、下、左、右均填 1.5 → 勾选「水平居中」。
  7. 设页脚。切到「页眉/页脚」选项卡 →「自定义页脚」→ 光标放进「中」框 → 输入「第 」→ 点「插入页码」按钮 → 输入「 页 共 」→ 点「插入总页数」按钮 → 输入「 页」→ 确定。
    生成的代码是 &[页码] 与 &[总页数]，不要手打数字。
  8. 预览。「文件」→「打印」（Ctrl+P）→ 右侧预览里翻页，确认：①每页顶部都有表头；②页脚显示「第 1 页 共 N 页」；③所有列都在一页宽内。
  9. 退出预览并保存。Esc 返回 → 保存为 学号-姓名-练习4-2.xlsx。
采分点打印区域为 A1:F60 · 顶端标题行为 $1:$1 · 缩放为 1 页宽 · 纸张 A4 横向 · 页边距四边 1.5 · 页脚为页码+总页数域且居中 · 预览中每页均有表头

易错提醒

  • 顶端标题行手打「1:1」：部分版本不认，必须点行号让系统写入 $1:$1。
  • 页脚用「第 1 页 共 8 页」手打：页数变化后不更新，评分按域判定。
  • 只设了「打印区域」没设「打印标题」：第 2 页起没有表头，这条分值必丢。
  • 缩放选了「调整为 1 页高」：60 行被压成一页，字小到看不清，方向也错。
  • 忘记设「水平居中」：内容偏左，打印类评分点可能扣。

打印前必看的三处

① 灰色虚线（分页线）是否切在表格中间；② 预览页数是否合理；③ 页脚/页眉是否只在第一页出现（那说明没设顶端标题行）。三处都对，打印类 4~6 分基本稳拿。

例 4-3

录入 20 行：序列 + 日期格式 + 下拉列表 + 金额格式 + 前导零

序列填充自定义格式数据有效性 16 分钟
题目要求
  1. 新建工作簿，A2:A21 填序号 1~20（用序列填充，不要手打）。
  2. B2 起输入日期，从 2026-09-01 开始按每天递增到 B21；格式显示为「2026年9月1日」。
  3. C 列用数据有效性做下拉列表：销售部 / 技术部 / 财务部 / 人事部。
  4. D 列销售额设为自定义格式 ¥#,##0.00。
  5. E 列工号为 001~020，必须保留前导零。
  6. 在 G1 用 COUNTIF 统计「销售部」的人数，G2 用 SUMIF 统计销售部销售额合计。
  7. 保存为 学号-姓名-练习4-3.xlsx。
解题步骤
  1. 新建保存。Ctrl+N → F12 存为 学号-姓名-练习4-3.xlsx。
  2. 序列填序号。A2 输入 1、A3 输入 2 → 同时选中 A2:A3 → 拖动右下角填充柄（小黑方块）到 A21。
    或用「开始」→「填充」→「序列」→ 步长 1、终止值 20。
  3. 填日期。B2 输入 2026-9-1 → 拖填充柄到 B21（默认按天递增）。
    若变成按年递增，松手后点右下角「自动填充选项」→ 选「以天数填充」。
  4. 设日期格式。选中 B2:B21 → Ctrl+1（设置单元格格式）→「数字」→ 分类选「自定义」→ 类型框输入 yyyy"年"m"月"d"日" → 确定。
    年月日三个字必须加英文双引号，否则会被识别成代码。
  5. 做下拉列表。选中 C2:C21 →「数据」→「有效性」（部分版本叫「数据验证」）→「设置」→ 允许选「序列」→ 来源框输入 销售部,技术部,财务部,人事部（英文逗号分隔）→ 确定。
  6. 设金额格式。选中 D2:D21 → Ctrl+1 →「自定义」→ 类型输入 ¥#,##0.00 → 确定。
  7. 保留前导零。先选中 E2:E21 → Ctrl+1 → 分类选「文本」→ 确定 → 再输入 001、002…
    （也可以输入时先打英文单引号 '001，效果相同。）顺序不能反：先输数字再改文本，零已经丢了。
  8. 统计人数。G1 输入 =COUNTIF(C2:C21,"销售部") → Enter。
  9. 统计销售额。G2 输入 =SUMIF(C2:C21,"销售部",D2:D21) → Enter。
  10. 保存。Ctrl+S。
采分点序号 1~20 为序列填充（非手打） · 日期 20 条且格式为「2026年9月1日」 · C 列为序列有效性下拉（点单元格出现箭头） · 金额格式为 ¥#,##0.00（显示两位小数） · 工号保留前导零（001） · COUNTIF 与 SUMIF 结果正确

易错提醒

  • 先输 001 再改成文本格式：零已经丢了，改格式也回不来。
  • 有效性来源用中文逗号：整串变成一个选项，下拉里只有一条。
  • 自定义格式里写了 yyyy年m月d日 但没加引号：年月日被当成代码，显示异常。
  • 日期用填充柄拖出 2026-9-1、2026-9-1…（全同）：要拖两个单元格形成规律再拖。
  • COUNTIF 的区域写成 C2:C20：少算最后一行。

自定义格式速记

0 强制占位（不补零）；# 有则显示、无则不显示；, 千分位；¥ 前缀；0.00 固定两位小数；[红色] 加颜色；@ 代表文本本身。

例 4-5

三种引用：跨表算金额、$B$10 算占比、$A2*E$1 做乘法表、名称算税额

绝对引用混合引用跨表名称 18 分钟
题目要求
  1. 打开素材（含「金额」「单价」「数量」「参数」四张表，参数!B2 = 0.13）。
  2. 在「金额」表 B2:B9 用相对引用计算 = 单价 × 数量（引用其他工作表）。
  3. 在 C2:C9 计算各产品金额占总额的比例，总额在 B10，要求下拉时总额不变（用绝对引用）。
  4. 在 E1:I9 用混合引用生成九九乘法表（第 1 行为 1~9，A 列也为 1~9）。
  5. 定义名称「税率」指向 参数!$B$2，在 D2:D9 用 =B2*税率 计算税额。
  6. 在 F12 用三维引用汇总 1 月、2 月、3 月三张表 B2 单元格之和。
  7. 保存为 学号-姓名-练习4-5.xlsx。
解题步骤
  1. 打开素材，先看清四张表的名称与结构。表名有空格或数字开头时，引用要加单引号（如 '1月'!B2）。
  2. 相对引用。在「金额」表 B2 输入 =单价!B2*数量!B2 → Enter → 选中 B2 拖填充柄到 B9。
    下拉后 B3 会自动变成 单价!B3*数量!B3——这就是相对引用的「跟着走」。
  3. 算占比（关键）。C2 输入 =B2/$B$10 → 下拉到 C9。
    $B$10 的行和列都被锁定，下拉时始终指向总额；写成 B10 就会变成 B11、B12（空白），结果显示 #DIV/0!。
  4. 设百分比格式。选中 C2:C9 → Ctrl+1 → 分类「百分比」→ 小数位数 1 → 确定。
  5. 铺乘法表的表头。E1 输入 1、F1 输入 2 → 选中 E1:F1 → 拖到 I1（得到 1~9）；
    A2 输入 1、A3 输入 2 → 选中拖到 A10（得到 1~9）。
  6. 写混合引用。E2 输入 =$A2*E$1 → Enter → 选中 E2 向右拖到 I2，再向下拖到 E10。
    理解方式：$A2 锁列不锁行（右拉时始终取 A 列），E$1 锁行不锁列（下拉时始终取第 1 行）。
  7. 验证乘法表。抽查 E3（=3×1=3）与 I9（=9×9=81），数值正确说明引用方向对。
  8. 定义名称。「公式」→「定义名称」→ 名称输入「税率」→ 引用位置输入 =参数!$B$2 → 确定。
  9. 用名称计算。D2 输入 =B2*税率 → 下拉到 D9。名称相当于给单元格取了个「外号」，公式里可直接用。
  10. 三维引用。F12 输入 =SUM('1月:3月'!B2) → Enter。
    若表名是「1月」「2月」「3月」，跨表区域写法为 '1月:3月'!B2；也可写成 =SUM('1月'!B2,'2月'!B2,'3月'!B2)。
  11. 保存。Ctrl+S。
采分点B2:B9 为跨表相对引用且结果正确 · C2:C9 使用 $B$10 绝对引用（下拉不错位） · E1:I9 用 $A2*E$1 混合引用生成完整乘法表 · 已定义名称「税率」并指向 参数!$B$2 · D 列用名称计算 · F12 三维引用求和正确

易错提醒

  • 占比写成 =B2/B10：下拉到 C9 时分母变成 B17，全是 #DIV/0!。
  • 乘法表写成 =A2*E1：右下角会引用到表格之外，数字全错。
  • 跨表引用漏了工作表名：只算当前表的 B2，结果明显偏小。
  • 表名以数字开头（1月）却不加单引号：公式报错或无法识别。
  • 定义名称时引用位置写相对引用：换表后指向错位。

$ 的一句话口诀

$ 在谁前面，谁就不动。$A$1 行列都不动（绝对）；$A1 列不动、行动；A$1 行不动、列动；A1 都动（相对）。不确定时按 F4 循环切换这四种。

例 4-6

公式基础：IFERROR 兜底、文本连接、比较运算与错误值排查

IFERROR文本连接错误值公式审核 14 分钟
题目要求
  1. 打开素材（B2:B9 有 2 个空白单元格，直接求平均会出错）。
  2. 在 B10 计算平均分，用 IFERROR 包裹，出错时返回 0。
  3. 在 C2 用 & 连接姓名与「同学」，下拉到 C9。
  4. 在 D2 用 IF 判断：成绩 ≥60 显示「及格」，否则「不及格」，下拉到 D9。
  5. 在 E2 用 AND 判断「语文、数学均 ≥60」是否成立，下拉到 E9。
  6. 在 G1:G6 列出 6 种常见错误值及含义（文字说明）。
  7. 在 H2 用「公式审核」查看 B10 的引用单元格。
  8. 保存为 学号-姓名-练习4-6.xlsx。

  1. 打开素材，选中 B2:B9 看状态栏计数——若「计数」小于「数值计数」，说明有空单元格。
  2. IFERROR 兜底。B10 输入 =IFERROR(AVERAGE(B2:B9),0) → Enter。
    IFERROR 的作用：公式正常就返回结果，报错就返回你指定的值（这里是 0）。
  3. 文本连接。C2 输入 =A2&"同学" → 下拉到 C9。
    若姓名在 A 列、学号在 B 列，也可 =A2&"（"&B2&"）" 组合多段文本。

    注意三个参数用英文逗号分隔，文本参数必须加英文双引号。
  5. AND 判断。E2 输入 =IF(AND(B2>=60,C2>=60),"是","否")（若素材只有一列成绩，可改为 =AND(B2>=60,TRUE) 演示语法）→ 下拉。

    #DIV/0! 除数为零或空
    #VALUE! 参数类型不对（文本参与四则运算）
    #REF! 引用的单元格被删除
    #NAME? 函数名拼错或未定义名称
    #N/A 查找函数找不到匹配值
    #NUM! 数值参数超出范围（如负数开平方）
  7. 公式审核。选中 B10 →「公式」→「追踪引用单元格」→ 出现蓝色箭头指向 B2:B9 → 说明公式确实引用了这些格。
    「移去箭头」可清除。
  8. 显示公式。按 Ctrl+`（反引号）可切换「显示公式/显示结果」，用于批量检查整表公式。

采分点B10 使用 IFERROR 包裹且不报错 · C 列为 & 连接结果（如「王雨桐同学」） · D 列 IF 判断正确 · E 列 AND 语法正确 · 6 种错误值含义写全 · 已演示追踪引用单元格

易错提醒

  • IF 的参数用中文逗号：公式直接报错，WPS 不会自动纠正。
  • 文本参数忘记加双引号：返回 #NAME?。
  • 用 IFERROR 掩盖真实错误：考试若要求「找出错误原因」，不能只靠兜底。
  • 把 0 写成 "0"：返回的是文本，后续参与计算会出错。
  • 认为空单元格等于 0：AVERAGE 会忽略空白，但 COUNTA 会计入，两者差异是常考点。

IFERROR 与 ISERROR 的区别

IFERROR(公式, 出错时的值) 一行搞定兜底；IF(ISERROR(公式), 值, 公式) 是旧写法，公式要写两遍。新版本一律用 IFERROR，WPS 与 Excel 都支持。

例 4-7

统计 6 件套 + 4 种取整 + MOD 判奇偶 + ABS 算偏差

统计函数取整MODABS 16 分钟
题目要求
  1. 打开素材（20 名学生，B 列语文、C 列数学、D 列英语）。
  2. 在 F2 计算总分（SUM），下拉到 F21。
  3. 在 G2 计算平均分，用 ROUND 保留 1 位小数，下拉。
  4. 在 B23:B27 分别用 MAX / MIN / AVERAGE / COUNT / COUNTA 计算最高分、最低分、全体平均、数值个数、非空个数。
  5. 在 H2:H4 分别用 ROUND / ROUNDUP / ROUNDDOWN 对 85.678 保留 1 位，对比结果。
  6. 在 I2 用 INT 取整、J2 用 MOD 判断行号奇偶（偶数返回「双」、奇数返回「单」）。
  7. 在 K2 用 ABS 计算该生总分与全体平均总分的偏差绝对值。
  8. 保存为 学号-姓名-练习4-7.xlsx。
解题步骤
  1. 打开素材，确认数据行为 2~21。
  2. 总分。F2 输入 =SUM(B2:D2) → Enter → 拖填充柄到 F21。
    B2:D2 是区域写法（冒号表示「到」），等价于 B2+C2+D2。
  3. 平均分并取整。G2 输入 =ROUND(AVERAGE(B2:D2),1) → 下拉到 G21。
    ROUND 的第二个参数是「保留几位小数」，1 表示四舍五入到 0.1。
  4. 五个统计值。B23 =MAX(F2:F21)；B24 =MIN(F2:F21)；B25 =AVERAGE(F2:F21)；B26 =COUNT(F2:F21)（只数数值）；B27 =COUNTA(A2:A21)（数非空，含文本）。
  5. 三种取整对比。H2 =ROUND(85.678,1) → 85.7；H3 =ROUNDUP(85.678,1) → 85.7（向上进位，若为 85.61 则得 85.7）；H4 =ROUNDDOWN(85.678,1) → 85.6（截断）。
    再试 =ROUNDUP(85.601,1) 与 =ROUNDDOWN(85.699,1) 才能看出三者差别。
  6. INT 取整。I2 输入 =INT(G2) → 结果为整数部分（向下取整，负数时与 TRUNC 不同）。
  7. MOD 判奇偶。J2 输入 =IF(MOD(ROW(),2)=0,"双","单") → 下拉。
    ROW() 取当前行号，MOD(行号,2) 为 0 即偶数行。
  8. ABS 偏差。K2 输入 =ABS(F2-$B$25) → 下拉到 K21。
    这里用 $B$25 锁定全体平均，下拉时才不会跑偏。

易错提醒

  • COUNT 与 COUNTA 混用：COUNT 只数数字，学号是文本时结果会小于人数。
  • ROUND 的第二参数写成 0.1：表示保留 0.1 位，结果异常。
  • MOD 的第二个参数为 0：返回 #DIV/0!。
  • ABS 里用了相对引用 B25：下拉后区域整体下移，偏差全错。
  • 用 INT 处理负数：INT(-2.5) = -3（向下取整），与直觉不同。

什么时候用 ROUND，什么时候用格式

格式只改「显示」，单元格里仍是原值，求和时会按原值算；ROUND 改的是「值」本身，后续计算用取整后的数。题目写「保留 1 位小数」通常指 ROUND；写「显示为 1 位小数」才是格式。

例 4-8

IF 三级跳：单条件 → 嵌套五级 → IFS + AND/OR 组合

IF嵌套IFSAND/OR 17 分钟
题目要求
  1. 打开素材（A 列姓名，B 列总分）。
  2. 在 C2 用 IF 判断及格（≥60 及格），下拉到 C21。
  3. 在 D2 用嵌套 IF 给出五级等级：≥90 优、≥80 良、≥70 中、≥60 及格、其余不及格，下拉。
  4. 在 E2 用 IFS 重写同一逻辑，下拉。
  5. 在 F2 用 AND 判断「语文、数学、英语三科均 ≥60」，返回「全科合格/有挂科」，下拉。
  6. 在 G2 用 OR 判断「三科中任一门 ≥90」，返回「有单科优秀/无」，下拉。
  7. 在 H2 用 IFERROR 包裹一个会出错的除法，验证兜底效果。
  8. 保存为 学号-姓名-练习4-8.xlsx。
解题步骤
  1. 单条件 IF。C2 输入 =IF(B2>=60,"及格","不及格") → 下拉到 C21。
  2. 嵌套 IF 的思路。从高到低判断，一旦命中就不再往下：
    D2 输入 =IF(B2>=90,"优",IF(B2>=80,"良",IF(B2>=70,"中",IF(B2>=60,"及格","不及格")))) → 下拉。
  3. 嵌套的括号数。4 层 IF 就有 4 组括号，写完后数一遍左右括号数量是否相等；WPS 输入时会自动提示当前处于第几层。
  4. IFS 重写。E2 输入 =IFS(B2>=90,"优",B2>=80,"良",B2>=70,"中",B2>=60,"及格",TRUE,"不及格") → 下拉。
    IFS 的写法是「条件1,结果1,条件2,结果2…」，最后用 TRUE 兜底。
  5. 核对两种写法。把 D 列与 E 列逐行对照，应完全一致；不一致说明条件顺序或边界值错。
  6. AND 组合。F2 输入 =IF(AND(B2>=60,C2>=60,D2>=60),"全科合格","有挂科")（按素材实际列位置调整）→ 下拉。
  7. OR 组合。G2 输入 =IF(OR(B2>=90,C2>=90,D2>=90),"有单科优秀","无") → 下拉。
  8. IFERROR 演示。H2 输入 =IFERROR(B2/0,"除数为零") → 显示「除数为零」而不是 #DIV/0!。
  9. 保存。Ctrl+S。
采分点C 列 IF 及格判断正确 · D 列嵌套 IF 五级等级正确（边界 90/80/70/60 无重叠无遗漏） · E 列 IFS 与 D 列结果完全一致 · F 列 AND、G 列 OR 逻辑正确 · H 列 IFERROR 生效

易错提醒

  • 嵌套 IF 的条件顺序写反（先判 ≥60）：所有分数都被判成「及格」。
  • 边界值重复（≥90 与 ≥80 都写 ≥90）：90 分可能落到错误等级。
  • IFS 最后没有兜底条件：低于 60 的行显示 #N/A。
  • AND 与 OR 混用不加括号：运算顺序不确定，结果不可预期。
  • 用中文引号包文本：公式报错，必须英文双引号。

嵌套 IF 超过 3 层怎么办

优先改用 IFS（清晰、不易错）；其次用 LOOKUP 或 VLOOKUP 近似匹配查等级表——这也是下一次课要练的内容。考场上写嵌套 IF 容易漏括号，建议先把模板写在草稿上。

本次课小结与交卷自查

做完 8 道题，用下面两张表各花 3 分钟过一遍——自查过的题，考场上才敢交卷。

✅ 交卷自查清单（做完逐项打勾）

  1. 工作表名称、标签颜色、顺序是否与题目一致
  2. 行高列宽是否为数值设定（不是拖出来的大概值）
  3. 冻结的是首行还是首列？拖动滚动条验证一次
  4. 打印区域是否包含全部数据、顶端标题行是否为 $1:$1
  5. 日期、金额、工号是否用了正确的格式代码（不是纯文本）
  6. 下拉列表是否用「序列」有效性做的（不是复制粘贴）
  7. 公式里的 $ 位置是否与「下拉/右拉」的方向匹配
  8. 跨表引用是否带了工作表名与感叹号（如 单价!B2）
  9. 所有公式是否复制到整列，而不是只算了第一行
  10. 文件名是否为 .xlsx，保存位置是否正确

🔻 本次课最容易丢分的 5 处

  • 引用没加 $——下拉后区域整体偏移，统计结果全错，这是表格题最致命的一处。
  • 工号丢了前导零——001 变 1，整个编号体系错位，且无法靠后期补。
  • 用空格冒充缩进/对齐——数据变成文本，后续函数算不出来。
  • 打印没设顶端标题行——第 2 页开始没有表头，打印类评分点全丢。
  • 条件格式只设了第一格——必须选中整列区域再设规则，否则只有一格变色。

考场时间提示

表格题建议 40 分钟：建表与格式 10 分钟 → 公式与函数 20 分钟 → 条件格式/打印 6 分钟 → 核对与保存 4 分钟。函数题卡住超过 3 分钟就先写「能算对的部分」，最后再回来补——表格题按点给分，空白比写错更亏。
