# 超纲边界与易误判考点

## 明确超纲：不需要深究

| 内容 | 为什么超纲 |
|---|---|
| **WPS 宏 / VBA / JS 编程** | 官方大纲无此条目；WPS 学堂的「宏使用教程」是职场提效内容，与考试无关。**完全跳过** |
| **WPS AI / 智能美化 / AI 排版** | 2025 年版大纲未涉及，样题操作题也未出现。注意 SmartArt 智能图形是考纲内的老功能，与 AI 排版是两回事 |
| **多维表格 / WPS 团队 / 协同办公进阶** | 属于 WPS 365 商业产品线，与二级考试三件套无关 |
| **WPS 组件（PDF 组件、DTP、邮件组件）** | 大纲只要求「了解 PDF 能力」，不需掌握完整组件功能 |
| **打印驱动 / 打印机硬件设置** | 只需会用「打印缩放 / 纸张方向 / 打印标题行」三个软件项 |
| **Python / JS 宏 / 插件开发** | 同宏，与本科目无关 |

## 看似超纲、实际在考纲内：不要漏

| 内容 | 实际位置 |
|---|---|
| **邮件合并** | 大纲二.7 明文列出，通关课专门一节 |
| **数据透视表** | 大纲三.6 单列一条，真题几乎每套出现，最高频被低估的考点 |
| **文档网格（只指定行网格、每页 N 行）** | 样题第 11 题 (2) 明确要求「每页 33 行」 |
| **多级编号高级用法** | 样题第 11 题 (4) 整题在考：编号末尾无点号、半角数字样式、编号后用空格代替制表符、级别间重新编号 |
| **交叉引用 + 域更新（F9）** | 样题第 11 题 (5)(6) 在考 |
| **SmartArt 智能图形** | 大纲四.3 明文列出 |
| **图片柔化边缘 / 置于底层** | 大纲「图像对象的编辑和应用」，样题 (8)③ 在考 |
| **自定义放映方案 / 动作按钮** | 大纲四.4「链接操作等交互设置」的延伸 |
| **公共基础知识 10 分** | 计入单选 20 分内，不要花超过 3 天，计算题（进制、容量）才是重点 |

## 一个反向提醒

有些资料会引导你准备**一级 WPS Office 应用**的内容（计算机基础 + WPS 基础操作，更简单）。你不需要——二级是「高级应用与设计」，涉及样式体系、引用体系、透视表、母版、动画这些一级完全不考的东西。看资源时先确认它标的是二级还是一级（通关课明确写「本教程适用版本：WPS Office 考试专用版」，这是对的信号；GitHub 题库混着两个级别的资料，要注意区分）。
