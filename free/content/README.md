## 文档教程

官方图文博客、技术专栏与官方 PDF 文件。适合按考点定点查阅、逐字核验参数，而不是从头刷。

资源原文见 `分类-docs.md`；对应站点页面 `category/docs.html`。

## 视频课程

WPS 官方学堂系统课与 B 站真题精讲。系统课按考纲顺序打底，真题讲解负责打通考场动线。

资源原文见 `分类-courses.md`；对应站点页面 `category/courses.html`。

## 开源项目

GitHub / Gitee 题库仓库与在线版自建备考站。可在线访问、可下载复用，但需留意版本时效。

资源原文见 `分类-opensource.md`；对应站点页面 `category/opensource.html`。

## 模板素材
