# 知识点分级学习顺序

> 三个模块各自的知识点递进层级，按依赖关系自下而上排列。

## 通用底层（三模块共享，先做）

| 层级 | 内容 | 为什么排在这里 |
|---|---|---|
| L0 界面与文件 | 功能区 / 选项卡结构、视图切换、新建保存另存、扩展名显示、文档属性 | 一切操作的入口 → 三门新手课第 1 章 + 通关课 1-2 |
| L0.5 快捷键 | Ctrl 系列、Shift / Alt 组合、F 键（**F4 引用切换、F9 更新域**）、Tab / Enter / Alt+Enter | 考场 120 分钟，快捷键就是时间；F9 尤其关键 |
| L0.8 素材与文件规范 | 考试固定给 `WPS.docx` / `ET.xlsx` / `WPP.pptx`，**后续操作均基于原文件，否则不得分**，不得增删幻灯片 | 这是评分规则不是知识点，但必须最先知道 |

## 文字处理（6 级）

| 层级 | 知识点 | 关键动作 | 资源 |
|---|---|---|---|
| L1 基础编辑 | 输入编辑、查找替换、格式刷、自动换行、插入空白页 | 格式刷连续使用、回车符 vs 换行符 | 文字新手课第 1 章 |
| L2 排版与样式 | 字符 / 段落格式、**样式**、**多级编号**、制表位 | 改样式而不是逐个改格式；会「在级别 1 后重新编号」 | 文字新手课第 2 章 → 通关课 2-1、2-2 |
| L3 页面与节 | 纸张页边距、**文档网格**、分栏、分页符 vs **分节符**、页眉页脚页码、水印 | 分节符是分水岭，不切断节则页眉页脚无法独立 | 文字新手课第 3 章 → 通关课「长文档排版」 |
| L4 引用体系 | **题注（含按章编号）**、**交叉引用**、自动目录、表 / 图目录、脚注尾注、书签 | 文字模块最难、最易失分 | 官方交叉引用图文 → 题注机制图文 → 通关课 2-3 → **真题讲解** |
| L5 表格与图文 | 文档内表格、图片环绕阴影柔化、艺术字、文本框、符号公式、**邮件合并** | 三线表样式是样题原题 | 通关课 2-4 → 真题讲解 |
| L6 审阅与其他 | 修订接受 / 拒绝、权限保护、多窗口、输出 PDF | 样题第 11 题 (11) 必考 | 通关课 → 官方样题 PDF |

## 表格处理（6 级）

| 层级 | 知识点 | 关键动作 | 资源 |
|---|---|---|---|
| L1 工作簿与录入 | 填充柄、Ctrl+D、Ctrl+E、单元格内换行、**分列**、格式刷 | 分列时把指定列设为「文本」是样题原话 | 表格新手课第 1—2 章 |
| L2 格式与引用 | 数字 / 日期自定义格式、冻结窗格、**相对 / 绝对 / 混合引用 + F4** | 引用是表格模块命门，样题 (10) 明确提醒 | 表格新手课第 1、4 章 |
| L3 函数 | SUM / COUNT 系列、COUNTIF(S)、SUMIF(S)、IF 族、**VLOOKUP**、RANK、DATEDIF | 优先级 VLOOKUP > 统计 > 文本 > 日期 | 通关课 5-1~5-5 → 表格新手课第 4 章 |
| L4 数据管理 | 排序、自动 / 高级筛选、分类汇总、合并计算、数据有效性、条件格式 | 条件格式 + 数据有效性是样题双杀 | 通关课 4-1~4-5 → 真题讲解 |
| L5 图表与透视表 | 饼图 / 柱形 / 折线、图例、百分比标签；**数据透视表与透视图** | 透视表是独立考点条目 | 透视表专项 → 通关课 5-6 |
| L6 输出与协作 | 打印缩放一页、打印标题行、分页预览、保护工作表、批注、超链接 | 送分但常被跳过 | 通关课「报表呈现与输出」 |

## 演示方向（5 级）

| 层级 | 知识点 | 关键动作 | 资源 |
|---|---|---|---|
| L1 基础与视图 | 幻灯片组织、视图模式、**批量替换字体与文本** | 统一改标题字体的最优路径是改母版 | 演示新手课第 1 章 → 通关课 6-2 |
| L2 版式与母版 | 主题版式、**幻灯片母版**、背景渐变、**隐藏背景图形**、Logo | 母版是杠杆，一个动作解决一整题 | 演示新手课第 3 章 → 通关课 6-3 |
| L3 对象与图形 | 文本框、艺术字预设样式、形状、**SmartArt**、图片裁剪 / 柔化 / 置于底层、图表、音视频 | 预设样式名称必须能对上 | 通关课 6-5~6-7 → SmartArt 官方图文 |
| L4 动画与切换 | 具体效果名、方向、开始方式、延迟、动画刷；切换效果与速度 | 样题 (3)(9) 专考，只能靠真题讲解记位置 | 通关课 6-8 → **真题讲解** |
| L5 交互与放映 | 超链接（跳转 / 返回目录 / 自定义放映 / 动作按钮）、自定义放映方案、文件打包 | 在母版里做超链接是纯考纲点 | 通关课 6-8~6-9 → 真题讲解 |
