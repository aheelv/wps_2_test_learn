数据来源、收录标准、免费限制总览、模板与许可证，以及静态资源站内化清单。

1. 站点定位与数据范围

本站把 2026-11-11 完成的《WPS 二级备考资源调研》中实际核验过的公开免费资源整理为可检索的静态索引， 面向全国计算机等级考试（NCRE）二级 WPS Office 高级应用与设计（科目代码 67）。 共 35 条资源、6 个语义分类、48 个外部获取入口，另含 2 份已随站点部署的官方 PDF。

收录标准：① 获取本身不需要付费；② 链接于核验当日实际访问；③ 能说清用途与限制。 未收录付费网盘题库、纸质出版物、无法核验免费状态的课程。虎课网等未核验来源仅作为「已检索但未采纳」记录保留，不计入推荐。

4. 三维评价方法

每条资源按三个维度判断定位，避免把真题课当入门课、把职场课当备考课：

  • 零基础友好度：是否从界面起步、颗粒度是否够细。
  • 图文结合度：是否有图文技巧、练习文档或分 P 文字目录可脱离视频复看。
  • 备考适配度：与 2025 年版考纲的映射精度、是否命中官方样题的真实难度。
如果只选三样：官方《计算机二级 高效通关课》（教「有哪些」）+ 大猫《WPS计算机二级真题讲解》（教「怎么做」）+ 官方样题 PDF（定「考到什么颗粒度」）。三门新手入门课当字典随时回查，不要从头到尾刷。

6. 静态资源站内化与外链政策

  • CSS / JS 全部随站点部署：模板 styles.css（内含 Bootstrap 5.2.3）、Bootstrap bundle.min.js、模板 scripts.js、站点 site.css / site.js、检索数据 resources.js 均为站内文件，不使用任何 CDN。
  • 图片全部站内：6 个分类线性图标与首页装饰图由站点自绘，以内联 SVG 嵌入页面（同时保留 assets/img/ 独立 SVG 文件），favicon 来自模板站内文件；原模板的 dummyimage.com 占位图已全部移除。图标内联可规避部分静态托管服务把 .svg 返回成非标准 MIME 导致的破图，页面不引用任何外部图片。
  • 字体使用系统字体栈，不加载外部字体。
  • 官方 PDF 站内副本：考纲与样题已存入 assets/files/，即使原站链接失效也可查看。
  • 内容外链为资源本身：详情页的「获取方式」链接指向原资源站点，属于内容而非页面依赖，均标注完整 URL 并在新窗口打开，页面加载不依赖它们。

├─ data/              resources.json / categories.json / resources.js（内容数据）

├─ tools/build.py     静态页面生成器

站点代码（assets/ 与根目录 HTML）与资源内容（data/、content/、assets/files/）分层存放； 新增或修改资源只需编辑 data/resources.json 后运行 python tools/build.py，页面与检索数据会同步重建。

本站部署于 GitHub Pages 子路径 /wps_2_test_learn/free/，正式入口为 https://aheelv.github.io/wps_2_test_learn/free/； 全部站内链接均为相对路径，因此在该子路径下页面、样式、脚本、附件与检索功能均可直接使用。
