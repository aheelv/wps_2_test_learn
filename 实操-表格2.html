💡 为什么这样排

「查找 → 提取 → 统计 → 重排」是数据处理的标准链路：先按关键字把信息取过来（查找引用），再从字符串/日期里拆出可用字段（文本日期），再做多条件汇总（数组与条件统计），最后按业务需要重排与筛选（排序筛选）。这也正是考试综合题的操作顺序。

小节01

查找与引用函数

VLOOKUP 四参数、IFERROR 兜底、近似匹配查等级、INDEX+MATCH 反向查找、INDIRECT 与 OFFSET。

45 分钟讲 10 / 练 352 道实操题考纲三·4

本小节必须掌握的知识点

  • VLOOKUP(查找值, 查找区域, 返回列号, 匹配方式) 四参数含义
  • 精确匹配 0/FALSE 与近似匹配 1/TRUE 的区别与前提
  • 查找区域绝对引用（$）与返回列号的数法
  • IFERROR 包裹查找，处理查不到的情况
  • INDEX + MATCH 实现反向查找与多条件查找
  • HLOOKUP 横向查找
  • INDIRECT 用文本构造引用（动态表名）
  • OFFSET 以基准点偏移构造动态区域
例 5-1

VLOOKUP 精确查姓名专业 + IFERROR 兜底 + 近似匹配算绩点

VLOOKUPIFERROR近似匹配 17 分钟
题目要求
  1. 打开素材（「成绩」表 A 列学号、B 列姓名（空）、C 列专业（空）、D 列总分；「学生信息」表 A 学号、B 姓名、C 专业）。
  2. 在「成绩」表 B2 用 VLOOKUP 精确匹配按学号查姓名，下拉到 B21。
  3. 在 C2 用同样方法查专业，下拉到 C21。查找区域必须绝对引用。
  4. 用 IFERROR 包裹，使查不到的学号显示「未找到」。
  5. 在 J1:K6 建立绩点对照表（0→0、60→1.0、70→2.0、80→3.0、90→4.0），在 F2 用近似匹配按总分返回绩点，下拉到 F21。
  6. 抽查 85 分的绩点应为 2.0（80 ≤ 85 < 90）。
  7. 保存为 学号-姓名-练习5-1.xlsx。
解题步骤
  1. 打开素材，先看方向。VLOOKUP 只能从左往右查：查找值必须位于查找区域的第 1 列。这里学号在两表都是 A 列，方向正确。
  2. 写姓名公式。B2 输入 =VLOOKUP($A2,学生信息!$A$2:$C$21,2,0) → Enter。
  3. 逐个参数确认。① 查找值 $A2：锁列不锁行，右拉时仍取学号列；② 区域 学生信息!$A$2:$C$21：跨表 + 全绝对，下拉不会漂移；③ 返回列号 2：从区域第 1 列（A 学号）数起，姓名是第 2 列；④ 匹配方式 0：精确匹配。
  4. 下拉。选中 B2 → 双击填充柄（或拖到 B21）。逐行检查是否有 #N/A。
  5. 查专业。C2 输入 =VLOOKUP($A2,学生信息!$A$2:$C$21,3,0) → 下拉。只有返回列号从 2 变成 3，其余不动。
  6. 加兜底。把 B2 改为 =IFERROR(VLOOKUP($A2,学生信息!$A$2:$C$21,2,0),"未找到") → 下拉。C2 同样处理。
  7. 建对照表。J1 输入「分数」、K1 输入「绩点」；J2:J6 依次 0、60、70、80、90；K2:K6 依次 0、1.0、2.0、3.0、4.0。
    首列必须升序，这是近似匹配的硬性前提。
  8. 近似匹配。F2 输入 =VLOOKUP(D2,$J$2:$K$6,2,1) → 下拉。
    第 4 参数 1（或 TRUE）表示「找不到精确值就取不超过它的最大值」。
  9. 验证边界。85 → 取 80 对应 2.0；90 → 取 90 对应 4.0；59 → 小于最小值，返回 #N/A（可用 IFERROR 兜成 0）。
  10. 保存。Ctrl+S。
采分点B2:B21 姓名查找正确且区域绝对引用 · C2:C21 专业正确（返回列号 3） · 两列均有 IFERROR 兜底 · 近似匹配第 4 参数为 1 且对照表升序 · 85 分绩点为 2.0

易错提醒

  • 区域写成 A2:C21 没加 $：下拉到第 10 行时区域已下移到 A12，前半段数据查不到。
  • 第 4 参数省略：默认按近似匹配，姓名会取到「最接近的」错误值，且不报错——最难发现。
  • 返回列号从 A 列开始数成 1：取回来的是学号。
  • 对照表没升序：近似匹配返回的结果毫无规律。
  • 把 IFERROR 写在 VLOOKUP 外面但少一个括号：整列报错。

VLOOKUP 四参数口诀

找谁、在哪找、取第几列、要不要精确。前两个决定成败，第三个决定拿到什么，第四个决定「找不到时怎么办」。考试里第 4 个参数写 0 永远比省略安全。

例 5-2

INDEX+MATCH 反向查学号 + HLOOKUP + INDIRECT 动态表名 + OFFSET

INDEX+MATCHHLOOKUPINDIRECTOFFSET 17 分钟
题目要求
  1. 打开素材（「学生信息」表 A 学号、B 姓名、C 专业；「季度销售」表首行为季度、第 2 行为金额）。
  2. 在 H2 用 INDEX+MATCH 按 I2 输入的姓名查学号（反向查找，VLOOKUP 做不到）。
  3. 在 H3 用 HLOOKUP 查「第三季度」的销售额。
  4. 在 H4 用 INDIRECT：根据 I4 中输入的表名（如「1月」），引用该表的 B2 单元格。
  5. 在 H5 用 OFFSET 求以 B2 为起点、5 行 3 列区域的总和。
  6. 保存为 学号-姓名-练习5-2.xlsx。
解题步骤
  1. 理解为什么用 INDEX+MATCH。VLOOKUP 只能「查找值在左、返回值在右」；按姓名查学号是「返回值在左」，必须换组合。
  2. 先写 MATCH。MATCH 的作用是「找位置」：MATCH(I2,学生信息!$B$2:$B$21,0) 返回姓名在 B 列中的第几个（相对位置）。
  3. 再套 INDEX。H2 输入 =INDEX(学生信息!$A$2:$A$21,MATCH(I2,学生信息!$B$2:$B$21,0)) → Enter。
    读法：在 A 列里，取「姓名所在的那个位置」的值。
  4. HLOOKUP。H3 输入 =HLOOKUP("第三季度",$B$1:$E$2,2,0) → Enter。
    HLOOKUP 与 VLOOKUP 只差一个方向：它在首行横向找，返回指定行号的值。
  5. INDIRECT。H4 输入 =INDIRECT("'"&I4&"'!B2") → Enter。在 I4 输入「1月」，公式就去取 '1月'!B2。
    单引号是为了兼容以数字开头或含空格的工作表名。
  6. 验证 INDIRECT。把 I4 改成「2月」，H4 的值应立即变为 2 月表的 B2——这就是「动态表名」。
  7. OFFSET。H5 输入 =SUM(OFFSET(B2,0,0,5,3)) → Enter。
    五个参数：基准点 B2、向下偏移 0 行、向右偏移 0 列、高度 5 行、宽度 3 列。
  8. 核对 OFFSET 区域。选中公式中的 OFFSET 部分按 F9 可临时看到它引用的区域内容，按 Esc 退出不改变公式。
  9. 保存。Ctrl+S。
采分点H2 为 INDEX+MATCH 组合且按姓名查到正确学号 · H3 为 HLOOKUP 且第 3 参数为 2、第 4 参数为 0 · H4 用 INDIRECT 拼接表名（含单引号） · H5 用 OFFSET 构造 5 行 3 列区域并求和

易错提醒

  • INDEX 与 MATCH 的区域长度不一致：MATCH 返回 15，INDEX 只到第 12 行，报 #REF!。
  • MATCH 第 3 参数写成 1：近似匹配，姓名会取到字母顺序最接近的错误值。
  • INDIRECT 拼接时漏了单引号：表名为「1月」时报错。
  • OFFSET 的高度宽度写反（3 行 5 列）：求出来的和不对，但不会报错。
  • 把 INDIRECT 用于跨工作簿引用：源文件关闭后返回 #REF!。

三种查找怎么选

VLOOKUP：查找值在左、返回值在右，最常用；HLOOKUP：表是横着排的；INDEX+MATCH：要反向查、或查找列经常增删（不受列号变化影响）。

例 5-3

18 位身份证提取：生日 + 性别 + 年龄 + 电话拆分 + 文本格式化

MIDMODDATEDIFSUBSTITUTETEXT 18 分钟
题目要求
  1. 打开素材（A 列姓名、B 列 18 位身份证号、C 列联系电话，如 0411-84711234）。
  2. 在 D2 用 MID 提取出生日期，显示为「1998-05-12」，下拉。
  3. 在 E2 用第 17 位判断性别（奇数为男），下拉。
  4. 在 F2 用 DATEDIF 计算年龄（周岁），下拉。
  5. 在 G2 用 RIGHT 取电话后 4 位，下拉。
  6. 在 H2 用 SUBSTITUTE 去掉电话中的「-」，下拉。
  7. 在 I2 用 TEXT 把 D2 显示为「1998年5月12日」。
  8. 在 J2 用 TEXTJOIN 把姓名与电话合并为「姓名：电话」。
  9. 保存为 学号-姓名-练习5-3.xlsx。
解题步骤
  1. 看清位置。18 位身份证：第 1~6 位地区码，第 7~14 位出生日期，第 15~17 位顺序码（第 17 位奇男偶女），第 18 位校验码。
  2. 取生日。D2 输入 =MID(B2,7,8) → 得到 19980512（文本）。
  3. 转成日期样式。把 D2 改为 =TEXT(MID(B2,7,8),"0000-00-00") → 得到 1998-05-12。
    0000-00-00 是「四位-两位-两位」的占位模板。
  4. 判断性别。E2 输入 =IF(MOD(MID(B2,17,1),2)=1,"男","女") → 下拉。
    读法：取第 17 位 → 除以 2 取余 → 余 1 为男。
  5. 算年龄。F2 输入 =DATEDIF(TEXT(MID(B2,7,8),"0000-00-00"),TODAY(),"y") → 下拉。
    DATEDIF 三个参数：起始日期、结束日期、单位（"y" 整年数）。
  6. 取电话后 4 位。G2 输入 =RIGHT(C2,4) → 下拉。
  7. 去掉连字符。H2 输入 =SUBSTITUTE(C2,"-","") → 下拉（得到 041184711234，前导 0 会丢，若需保留可外套 TEXT）。
  8. 格式化显示。I2 输入 =TEXT(D2,"yyyy年m月d日") → 显示「1998年5月12日」。
    注意 D2 已是文本日期，TEXT 会先识别再格式化；若 D2 是真正日期序列值，效果相同。
  9. 合并文本。J2 输入 =TEXTJOIN("：",TRUE,A2,C2) → 得到「王雨桐：0411-84711234」。
    TEXTJOIN 的第一参数是分隔符，第二参数 TRUE 表示忽略空单元格。
  10. 保存。Ctrl+S。
采分点D 列 MID 起始位 7、长度 8 且显示为 1998-05-12 · E 列性别判断取第 17 位且奇男偶女 · F 列 DATEDIF 用 "y" 且结果正确 · G 列 RIGHT 取 4 位 · H 列 SUBSTITUTE 去掉全部「-」 · I 列 TEXT 格式正确 · J 列 TEXTJOIN 分隔符与忽略空值正确

易错提醒

  • MID 起始位写成 6 或长度写成 6：生日错位（取到 619980 之类）。
  • 性别取第 18 位（校验码）：男女全错。
  • DATEDIF 起始日期是文本而非日期：返回 #NUM! 或 #VALUE!。
  • TEXTJOIN 第二参数写 FALSE：空单元格会多出分隔符。
  • SUBSTITUTE 只替换第一处：需确认是否有多个「-」（第三参数省略时默认全部替换）。

DATEDIF 的单位

"y" 整年数、"m" 整月数、"d" 天数、"ym" 除年外的月数、"md" 除月外的天数、"yd" 除年外的天数。算工龄用 "y"，算「几年几个月」用 "y" 与 "ym" 拼接。

例 5-4

日期函数：工龄、合同到期（EDATE）、月末（EOMONTH）、工作日

DATEDIFEDATEEOMONTHWORKDAY 16 分钟
题目要求
  1. 打开素材（A 姓名、B 入职日期、C 合同年限（年））。
  2. 在 D2 计算工龄（整年）：用 today 与 DATEDIF，下拉。
  3. 在 E2 计算「入职满几年几个月」的月数部分（"ym"），下拉。
  4. 在 F2 用 EDATE 计算合同到期日 = 入职日期 + 合同年限×12 个月。
  5. 在 G2 用 EOMONTH 计算入职当月的最后一天。
  6. 在 H2 用 WORKDAY 计算入职后第 15 个工作日（跳过周末）。
  7. 在 I2 用 NETWORKDAYS 计算入职到今天的有效工作日数。
  8. 在 J2 用 YEAR / K2 用 MONTH 提取入职年份与月份。
  9. 保存为 学号-姓名-练习5-4.xlsx。
解题步骤
  1. 算工龄。D2 输入 =DATEDIF(B2,TODAY(),"y") → 下拉。
    TODAY() 不带参数，返回当天日期，每次打开文件自动更新。
  2. 算零头月数。E2 输入 =DATEDIF(B2,TODAY(),"ym") → 下拉。结果为「除去整年之后剩下的月数」。
  3. 算到期日。F2 输入 =EDATE(B2,C2*12) → 下拉。
    EDATE 的作用是「在指定日期上加/减若干个月」，自动处理大小月与闰年。
  4. 设日期格式。选中 F2:F21 → Ctrl+1 → 日期 → 选「yyyy-mm-dd」或自定义 yyyy"年"m"月"d"日"。
  5. 算月末。G2 输入 =EOMONTH(B2,0) → 返回入职当月的最后一天。第二参数 0 表示当月，1 表示下月月末，-1 表示上月月末。
  6. 第 15 个工作日。H2 输入 =WORKDAY(B2,15) → 从入职日起往后数 15 个工作日（自动跳过周六周日）。
    若需排除法定节假日，用第四参数（节假日区域）。
  7. 工作日天数。I2 输入 =NETWORKDAYS(B2,TODAY()) → 返回两日期之间的工作日数（含首尾）。
  8. 提取年月。J2 输入 =YEAR(B2)；K2 输入 =MONTH(B2) → 下拉。
  9. 核对。抽查一人：入职 2019-03-15、合同 3 年，到期日应为 2022-03-15。
  10. 保存。Ctrl+S。
采分点D 列 DATEDIF 用 "y" · E 列用 "ym" 且结果 < 12 · F 列 EDATE 参数为 C2*12 且到期日正确 · G 列 EOMONTH 第二参数为 0 · H 列 WORKDAY、I 列 NETWORKDAYS 用法正确 · J/K 列年月提取正确

易错提醒

  • EDATE 写成 DATE：DATE 需要年月日三个参数，会报错。
  • EDATE 第二参数直接用合同年限（3）：只加 3 个月，不是 3 年。
  • DATEDIF 的起始日期晚于结束日期：返回 #NUM!。
  • WORKDAY 与 NETWORKDAYS 用反：一个返回日期，一个返回天数。
  • 把 TODAY() 写成 TODAY：返回的是文本「TODAY」，报 #NAME?。

TODAY 与 NOW 的刷新

两者都是易失性函数，每次重算/打开都会变。若题目要求「截至 2026-09-01 的天数」，不要用 TODAY()，直接写日期常量 DATE(2026,9,1)，否则过几天数字就变了。

例 5-5

多条件求和三种写法：SUMPRODUCT / SUMIFS / 数组公式 + 去重计数

SUMPRODUCTSUMIFS数组公式 18 分钟
题目要求
  1. 打开素材（销售明细：A 日期、B 部门、C 产品、D 数量、E 单价、F 金额，共 30 行）。
  2. 在 H2 用 SUMPRODUCT 求「销售部」且「笔记本」的金额合计。
  3. 在 H3 用 SUMIFS 求同一结果，验证两法一致。
  4. 在 H4 用 COUNTIFS 统计「技术部」且金额 > 5000 的记录数。
  5. 在 H5 用 AVERAGEIFS 求「财务部」的平均金额。
  6. 在 H6 用数组公式求「笔记本」的最高金额（Ctrl+Shift+Enter）。
  7. 在 H7 用 SUMPRODUCT(1/COUNTIF(...)) 统计不同部门的个数。
  8. 保存为 学号-姓名-练习5-5.xlsx。
解题步骤
  1. SUMPRODUCT 思路。把每个条件写成「真/假」数组，再与金额数组相乘：真=1、假=0，乘起来就把不符合的项清零了。
  2. H2 公式。=SUMPRODUCT((B2:B31="销售部")*(C2:C31="笔记本")*F2:F31) → Enter（普通回车即可）。
    注意三层括号：两个条件各一层，最外层是 SUMPRODUCT。
  3. H3 用 SUMIFS 验证。=SUMIFS(F2:F31,B2:B31,"销售部",C2:C31,"笔记本") → Enter。求和区域在最前，之后是「条件区域, 条件」成对出现。
  4. 比较两值。H2 与 H3 必须完全相等；不等说明条件拼写或区域范围不一致。
  5. H4 多条件计数。=COUNTIFS(B2:B31,"技术部",F2:F31,">5000") → Enter。
    条件里的 >5000 必须整体加英文双引号。
  6. H5 条件平均。=AVERAGEIFS(F2:F31,B2:B31,"财务部") → Enter。
  7. H6 数组公式。输入 =MAX(IF(C2:C31="笔记本",F2:F31)) → 按 Ctrl+Shift+Enter（不是普通回车）。
    成功后编辑栏会显示 {=MAX(IF(...))}，大括号是自动加的，不能手打。
  8. H7 去重计数。=SUMPRODUCT(1/COUNTIF(B2:B31,B2:B31)) → Enter。
    原理：每个部门出现 n 次就贡献 1/n，合计正好 1；把全部加起来就是「有多少个不同的部门」。
  9. 保存。Ctrl+S。
采分点H2 SUMPRODUCT 多条件结果正确 · H3 SUMIFS 求和区域在最前且结果与 H2 一致 · H4 COUNTIFS 条件 ">5000" 写法正确 · H5 AVERAGEIFS 正确 · H6 数组公式有大括号（三键输入） · H7 去重计数结果等于实际部门数

易错提醒

  • SUMIFS 把求和区域写在中间：参数顺序与 SUMIF 相反，直接报错或算错。
  • 条件里的 >5000 没加引号：公式报错。
  • 数组公式按普通回车：只对第一行生效，结果偏小。
  • 手动输入 {} 想冒充数组公式：WPS 会当成文本。
  • SUMPRODUCT 条件区域长度不一致（B2:B31 与 F2:F30）：返回 #VALUE!。

什么时候必须用数组公式

需要在「条件筛选后的子集」上做不只是求和/计数的运算时（如 MAX、MIN、MEDIAN、AVERAGE 的条件版），就得用 IF 数组公式或 MAXIFS（新版函数）。求和多条件优先用 SUMIFS，最简单。

例 5-6

排名与分段：RANK.EQ + LARGE/SMALL + MEDIAN + PERCENTILE + 五段统计

RANK.EQLARGEMEDIAN分段统计 15 分钟
题目要求
  1. 打开素材（A 姓名、B 总分，20 人）。
  2. 在 C2 用 RANK.EQ 计算名次（降序），下拉到 C21。
  3. 在 D2 用 LARGE 取第 3 名分数，在 D3 用 SMALL 取倒数第 2 名。
  4. 在 D4 用 MEDIAN 求中位数，D5 用 PERCENTILE 求第 90 百分位。
  5. 在 F2:F6 用 COUNTIFS 分段统计人数：≥90、80~89、70~79、60~69、<60。
  6. 在 G2:G6 计算各段人数占比（用 $F$7 总数做分母）。
  7. 保存为 学号-姓名-练习5-6.xlsx。
解题步骤
  1. 排名。C2 输入 =RANK.EQ(B2,$B$2:$B$21,0) → 下拉。
    第三参数 0 表示降序（分数越高名次越靠前）；写 1 表示升序。
  2. 验证排名。最高分那行的名次应为 1；两人同分时会出现并列名次（如两个第 3），这是 RANK.EQ 的正常行为。
  3. 取第 N 名。D2 输入 =LARGE($B$2:$B$21,3) → 第 3 大的分数；D3 输入 =SMALL($B$2:$B$21,2) → 第 2 小的分数。
  4. 中位数。D4 输入 =MEDIAN($B$2:$B$21)。中位数与平均数的差，能看出分数是否偏斜。
  5. 百分位。D5 输入 =PERCENTILE($B$2:$B$21,0.9) → 第 90 百分位，意思是「90% 的人低于这个分数」。
  6. 分段①≥90。F2 输入 =COUNTIFS($B$2:$B$21,">=90")。
  7. 分段②80~89。F3 输入 =COUNTIFS($B$2:$B$21,">=80",$B$2:$B$21,"<=89")。
    区间必须首尾相接、不重叠，否则会有分数被算两次或一次不算。
  8. 其余三段。F4 >=70 且 <=79；F5 >=60 且 <=69；F6 <60。
  9. 核对总数。F7 输入 =SUM(F2:F6)，应等于 20；不等说明区间有重叠或遗漏。
  10. 算占比。G2 输入 =F2/$F$7 → 下拉到 G6 → 设为百分比格式 1 位小数。
  11. 保存。Ctrl+S。
采分点C 列 RANK.EQ 降序且引用区域绝对 · D2/D3 LARGE 与 SMALL 的 N 值正确 · D4 MEDIAN、D5 PERCENTILE 正确 · 五段人数之和等于 20（区间不重叠） · 占比用 $F$7 绝对引用

易错提醒

  • RANK.EQ 的区域没锁 $：下拉后区域下移，排名全乱。
  • 分段区间写成 ≥80 与 <80 之外又写 ≥70：80 分被算两次。
  • PERCENTILE 第二参数写成 90：应填 0.9（百分位是用小数表示的）。
  • LARGE 写成 LARGE(B:B,3)：整列引用会把表头文本算进去，结果可能偏。
  • 占比用相对引用 F7：下拉后分母逐行下移，最后几行变 #DIV/0!。

RANK 与 RANK.EQ 的区别

旧函数 RANK 仍可用，RANK.EQ 是等价的新写法（并列时给相同名次）。另一个 RANK.AVG 在并列时取平均名次。考试写 RANK.EQ 或 RANK 都能得分。

例 5-7

双关键字排序 + 自定义序列 + 按颜色排序 + 自动筛选

多关键字排序自定义序列自动筛选 15 分钟
题目要求
  1. 打开素材（A 部门、B 姓名、C 产品、D 金额，30 行）。
  2. 先按「部门」升序、再按「金额」降序做双关键字排序。
  3. 撤销排序，改为按自定义序列排序：销售部 → 技术部 → 财务部 → 人事部。
  4. 给「金额」列最大的 3 个单元格填充红色，然后按单元格颜色排序（红色在前）。
  5. 用自动筛选筛选出「金额」前 10 项。
  6. 再改为筛选「产品」包含「笔记本」的记录。
  7. 保存为 学号-姓名-练习5-7.xlsx。
解题步骤
  1. 排序的正确选法。点数据区任意一个单元格（不要全选整列）→「数据」→「排序」。WPS 会自动识别整张表。
    若手动选区域，务必包含表头并勾选「数据包含标题」。
  2. 双关键字。「排序」对话框 → 主要关键字「部门」、次序「升序」→ 点「添加条件」→ 次要关键字「金额」、次序「降序」→ 确定。
  3. 自定义序列。再次打开「排序」→ 主要关键字「部门」→ 次序下拉选「自定义序列」→ 在右侧列表里找「销售部, 技术部, 财务部, 人事部」；若没有，在「输入序列」框里逐行输入（每行一个）→「添加」→ 选中它 → 确定。
  4. 标红前三。先按金额降序排一次，把前 3 行的金额单元格填充红色 → 再按原有顺序恢复（或不恢复，题目只要求能排序）。
  5. 按颜色排序。「数据」→「排序」→ 主要关键字选「金额」→ 次序选「单元格颜色」→ 在颜色下拉里选红色、位置「在顶端」→ 确定。
  6. 开自动筛选。点数据区任一单元格 →「数据」→「筛选」（或 Ctrl+Shift+L）→ 表头出现下拉箭头。
  7. 前 10 项。点「金额」列的下拉箭头 →「数字筛选」→「前 10 项」→ 对话框里确认「最大 10 项」→ 确定。
  8. 文本包含。先清除上一步筛选（「数据」→「清除」）→ 点「产品」下拉箭头 →「文本筛选」→「包含」→ 输入「笔记本」→ 确定。
  9. 观察行号。筛选后左侧行号会跳号（如 1、3、7…），说明是「隐藏」而非「删除」，这一点常被考到。
  10. 保存。Ctrl+S。
采分点双关键字排序顺序正确（部门升序 + 金额降序） · 自定义序列排序结果符合指定部门顺序 · 按单元格颜色排序红色在顶端 · 自动筛选前 10 项正确 · 文本包含筛选正确

易错提醒

  • 排序前手动选中了部分列：只有选中区域被重排，整行数据错位——这是最严重的一种错。
  • 自定义序列输入时用了中文逗号：变成一个长序列项，排序无效。
  • 按颜色排序时选了「字体颜色」：填充色不会生效。
  • 把筛选当成删除：筛选只是隐藏，取消筛选数据会回来；若误删需立即撤销。
  • 筛选状态下做排序：只在可见行内排，隐藏行不动，结果错乱。

排序前的一句提醒

如果表里有公式引用了「行位置」，排序后引用会跟着行走，结果可能变化。所以先排序、后写公式，或者公式里用绝对引用/整列引用，避免被排序打乱。

例 5-8

高级筛选：条件区域的「与/或」+ 结果复制到指定位置 + 不重复记录

高级筛选条件区域不重复记录 16 分钟
题目要求
  1. 打开素材（A1:F31 销售明细）。
  2. 在 H1:I2 建立条件区域：部门 = 销售部 且 金额 > 5000（同一行）。
  3. 用高级筛选把结果复制到 A35 开始的区域。
  4. 在 H5:I6 建立「或」条件：部门 = 销售部 或 部门 = 技术部（不同行）。
  5. 用高级筛选筛选出这两类记录，结果复制到 H10。
  6. 用高级筛选的「选择不重复的记录」提取所有不同的部门（复制到 H30）。
  7. 保存为 学号-姓名-练习5-8.xlsx。
解题步骤
  1. 理解条件区域规则。条件区域的第一行必须是与原表完全一致的字段名；同一行的多个条件是「与」，不同行是「或」。
  2. 建「与」条件。H1 输入「部门」、I1 输入「金额」；H2 输入「销售部」、I2 输入 >5000。
    字段名可以从原表直接复制，避免多空格。
  3. 启动高级筛选。点数据区任一单元格 →「数据」→「高级筛选」。
  4. 设三个区域。「方式」选「将筛选结果复制到其他位置」→ 列表区域 $A$1:$F$31 → 条件区域 $H$1:$I$2 → 复制到 $A$35 → 确定。
  5. 检查结果。A35 起应有表头 + 符合条件的记录，且每行金额都 > 5000、部门都是销售部。
  6. 建「或」条件。H5 输入「部门」；H6 输入「销售部」；H7 输入「技术部」（同一列、不同行）。
    注意此处不需要第二列字段名，只写一列即可表达「或」。
  7. 再筛选。「数据」→「高级筛选」→ 列表区域 $A$1:$F$31 → 条件区域 $H$5:$H$7 → 复制到 $H$10 → 确定。
  8. 不重复记录。「数据」→「高级筛选」→ 列表区域 $A$1:$F$31 → 不设条件区域 → 勾选「选择不重复的记录」→ 复制到 $H$30 → 确定。
    若只想提取部门列，可先单独选中 B 列再操作。
  9. 核对条数。用 COUNTA 数一下结果行数，与手工筛选的结果比对。
  10. 保存。Ctrl+S。
采分点「与」条件区域同一行且字段名与原表一致 · 高级筛选结果复制到 A35 且记录全部符合 · 「或」条件在不同行 · 结果复制到 H10 · 不重复记录提取成功 · 三次筛选的列表区域均为绝对引用

易错提醒

  • 条件区域字段名与表头差一个空格：筛选结果为空，且几乎看不出原因。
  • 「与」条件写在不同行：变成「或」，结果条数明显变多。
  • 复制到的位置与条件区域重叠：结果覆盖掉条件，第二次筛选就错。
  • 条件写 5000 而不是 >5000：变成「精确等于 5000」。
  • 「不重复的记录」勾了但同时设了条件区域：先去重再筛选，结果不符合预期。

高级筛选三句话

① 字段名必须一字不差；② 同行是与、异行是或；③ 复制到的位置必须留足空行，且不能与条件区重叠。记住这三句，这题基本不会错。

  • 高级筛选条件区域字段名多一个空格——筛选结果为空，且很难看出原因。

本课对应考试中「表格综合题」，建议 40 分钟：查找引用 12 分钟 → 文本日期 10 分钟 → 多条件统计 10 分钟 → 排序筛选 5 分钟 → 核对 3 分钟。凡是标注「用两种方法验证」的题，第二种方法只写公式不必美化，验证一致即可。
