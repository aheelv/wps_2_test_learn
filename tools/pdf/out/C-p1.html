使用说明

演示文稿操作题占 20 分，是三个模块里分值最低、但性价比最高的一块：题量小、步骤固定、评分点集中。它的特点是「一步没做对，后面全乱」——母版没改，所有幻灯片的字体都不对；版式没套，占位符里就没有内容。

本部分把第 7—8 课时的 8 个小节重组为一条工序：① 搭结构（幻灯片与视图）② 定视觉（主题、背景、母版）③ 填内容（文本、图形、图片、图表、音视频）④ 加动效（动画、切换、链接）⑤ 交付（放映、打包、输出）。这条工序就是考场上应该走的顺序。

1.1.1

演示文稿基本操作与幻灯片管理

考纲 四·1
核心内容
  • 新建空白演示文稿、保存与另存为 .pptx；幻灯片大小 16:9（宽屏）／4:3（标准）／自定义
  • 从大纲导入：新建 → 幻灯片（从大纲）→ 选择 Word／txt 文件，按标题级别生成多张幻灯片
  • 版式套用：标题幻灯片、标题和内容、两栏内容、仅标题、空白、图片与标题；右键 → 版式
  • 幻灯片的新建（Ctrl+M）、复制（Ctrl+D）、删除、拖动重排、隐藏（右键 → 隐藏幻灯片）
  • 分节：右键 → 新增节 → 重命名节；节可折叠，用于长演示文稿的结构管理
  • 五种视图：普通、大纲、幻灯片浏览、备注页、阅读；「视图」选项卡切换
  • 备注：普通视图下方备注栏输入，可打印为备注页；幻灯片编号从 0 还是 1 开始可设
关键操作路径
  • 开始 → 新建幻灯片 → 幻灯片（从大纲）
  • 视图 → 幻灯片浏览（一次看全部，拖动重排最快）
  • 右键幻灯片缩略图 → 新增节 / 隐藏幻灯片

下图把本节「关键操作路径」标在真实界面上：橙色编号与路径同序，图例给出按钮全名，照数字依次点即可。

易错
  • 大纲导入后每张幻灯片的版式是「标题和内容」，图片页需手动改为「仅标题」或「空白」，否则占位符会挡住图片。
  • 隐藏幻灯片只是放映时跳过，编辑视图里仍然存在，别误以为已删除。
1.1.2

主题应用、背景设置与母版制作

考纲 四·2
核心内容
  • 主题：设计 → 主题库；「变体」是同一主题下的配色／字体／效果组合，可单独替换配色方案与字体方案
  • 背景格式：纯色填充、渐变填充（预设／自定义光圈与方向）、图片或纹理填充（拉伸／平铺／居中）
  • 「应用到全部」与「重置背景」；「隐藏背景图形」用于单页去掉母版装饰
  • 幻灯片母版：视图 → 幻灯片母版；最上方是母版，下方是各版式，母版改动影响所有使用该版式的页面
  • 占位符：母版中选中标题／正文占位符改字体字号，所有页面同步；可插入 logo 图片（固定在母版上）
  • 页码／日期／页脚：插入 → 页眉和页脚 → 勾选「幻灯片编号」「日期和时间」（可固定或自动更新）
  • 新建自定义版式：插入版式 → 重命名 → 插入占位符（内容／文本／图片／图表），供后续页面套用
关键操作路径
  • 视图 → 幻灯片母版（编辑完点「关闭母版视图」）
  • 设计 → 变体 → 配色 / 字体 / 效果
  • 设置背景格式 → 图片或纹理填充 → 插入图片 → 拉伸

易错
  • 在普通视图里改字体只改当前页；要全文统一必须进母版改占位符。
  • 母版里插的 logo 若放在版式上，只影响该版式的页面；放在最上层母版上才影响全部。
1.1.3

文本、艺术字、图形与智能图形

考纲 四·3
核心内容
  • 占位符文字与文本框的区别：占位符受版式控制、可在大纲视图编辑；文本框是自由对象
  • 文本格式：字体字号、行距（1.0／1.5／固定值）、段前段后、文字方向（竖排）、分栏（两栏）
  • 项目符号：项目符号和编号 → 自定义（符号／图片／字符）；级别与缩进；编号起始值
  • 艺术字：插入 → 艺术字；文本效果（阴影／映像／发光／棱台／三维旋转），可「转换」为弯曲路径
  • 形状：绘制、更改形状、编辑顶点（右键 → 编辑顶点，拖控制柄改弧度）；形状填充、轮廓、效果
  • 对齐与分布、组合（Ctrl+G）、叠放次序（上移／下移一层／置于顶层／置于底层）
  • 智能图形：插入 → 智能图形 → 列表／流程／循环／层次／关系／矩阵；文本窗格 Tab 降级；可「转换为形状」
关键操作路径
  • 插入 → 艺术字 → 选择样式 → 绘图工具 → 文本效果
  • 插入 → 形状 → 右键 → 编辑顶点
  • 插入 → 智能图形 → 层次结构 → 文本窗格录入

图片、图表、音频与视频对象

考纲 四·3
核心内容
  • 插入图片（本地／联机）；图片工具：裁剪（按比例／裁剪为形状／裁剪填充）、大小与旋转

  • 删除背景（标记要保留／删除的区域）、颜色（饱和度／色调／重新着色）、压缩图片（220／150／96 ppi）

1.2.1

对象动画与幻灯片切换

考纲 四·4
核心内容
  • 四类动画：进入（淡出／飞入／擦除）、强调（放大／更改颜色／脉冲）、退出（消失／飞出）、动作路径（直线／自定义）
  • 动画窗格：序号、对象名、开始方式、持续时间四列；右键可「效果选项」设平滑开始／结束、重复次数
  • 开始方式三种：单击时、与上一动画同时、上一动画之后（做「依次出现」用「之后」最省事）
  • 持续时间（秒）与延迟（秒）的差别：延迟是「等多久开始」，持续时间是「演多久」
  • 动画顺序调整（鼠标拖动或「向前／向后移动」）、删除动画、动画刷（复制动画到另一对象）
  • 切换效果：推入／擦除／分割／淡出；效果选项（方向：自左／自右；形状：圆形／菱形）
  • 换片方式：单击鼠标／设置自动换片时间；排练计时（幻灯片放映 → 排练计时）记录每页停留时长
关键操作路径
  • 动画 → 动画窗格 → 右键动画 → 效果选项 → 计时
  • 切换 → 效果选项 → 设置自动换片时间
  • 幻灯片放映 → 排练计时 → 保存计时

下图把本节「关键操作路径」标在真实界面上：橙色编号与路径同序，图例给出按钮全名，照数字依次点即可。

易错
  • 「持续时间」设成 2 秒、「延迟」也设 2 秒，实际是「等 2 秒再演 2 秒」，共 4 秒——两个参数别混。
  • 切换的「全部应用」会把当前效果套到所有页，若只需某几页，逐页设。
1.2.2

超链接、交互设置与放映控制

考纲 四·4 · 四·5
核心内容
  • 超链接四种目标：本文档中的位置（某张幻灯片）、现有文件或网页、新建文档、电子邮件地址
  • 给文本设链接（选中文字 → 插入 → 超链接）与给形状／图片设链接（选中对象 → 插入 → 超链接）入口相同，但链接载体不同
  • 动作按钮：插入 → 形状 → 动作按钮（返回／首页／下一页／末页／影片）；「单击鼠标」行为可设为「超链接到」或「运行程序」
  • 编辑与取消超链接（右键 → 编辑／取消超链接）；链接颜色可在主题配色中改
  • 自定义放映：幻灯片放映 → 自定义放映 → 新建（选幻灯片、排顺序），一个文件可有多套放映方案
  • 设置放映方式：演讲者放映（全屏，可用演讲者视图）、观众自行浏览（窗口）、在展台浏览（全屏循环，Esc 无效）
  • 演讲者视图：放映时按 Alt+F5 或「使用演示者视图」，主讲人可见备注与下一张，观众只见当前页

  • 插入 → 形状 → 动作按钮：返回
  • 幻灯片放映 → 自定义放映 → 新建

★☆☆☆ · 18 分钟 · 30 分
操作目标

具体要求
  1. 新建空白演示文稿，幻灯片大小设为 16:9 宽屏；保存为 学号-姓名-P-01.pptx。
  2. 用大纲导入方式生成 8 张幻灯片（大纲文件见下表，一级标题成一页、二级标题成该页正文）。
  3. 第 1 页套用「标题幻灯片」版式；第 2—7 页套用「标题和内容」；第 8 页套用「仅标题」。
  4. 为第 8 页在标题下插入一个横排文本框，内容「谢谢观看」，黑体 40 号、居中。
  5. 把第 2—7 页分为 3 个节：「现状」「对策」「保障」，节名与页面对应关系自定但需合理。
  6. 在幻灯片浏览视图中把第 8 页移动到第 7 页之前，再用「撤销」恢复原顺序。
  7. 隐藏第 7 页，并说明放映时会跳过该页。
  8. 为每页添加备注：第 1 页备注写演讲者姓名与日期，其余页备注写一句讲解要点。

P-02

主题与背景：让 8 页看起来是一套

★★☆☆ · 25 分钟 · 34 分
操作目标

用主题 + 变体统一视觉，用渐变与图片背景做封面，掌握「应用到全部」「隐藏背景图形」这两个易漏选项。

具体要求
  1. 为整个演示文稿应用主题「离子」（或任一深色商务主题），并选择变体中蓝色配色方案。
  2. 把主题字体方案改为「微软雅黑」标题 + 「微软雅黑」正文；确认所有页面标题与正文字体同步变化。
  3. 第 1 页（封面）设置图片背景：插入一张校园图片，填充方式为拉伸，并「应用到全部」后再对第 1 页单独调整（说明两者差别）。
  4. 第 2 页设置渐变背景：线性、方向「线性向下」、两个光圈（浅蓝 0% → 深蓝 100%）。
  5. 第 3 页设置纯色背景 RGB(240,246,252)，并勾选「隐藏背景图形」，使母版装饰不显示。
  6. 为第 8 页设置纹理背景（画布纹理），平铺方式为「平铺」。
  7. 把第 1 页的图片背景重置为跟随主题，验证「重置背景」与「应用到全部」的作用范围。
  8. 在「设计 → 幻灯片大小」中确认 16:9，并说明若改为 4:3 会出现什么情况（内容被压缩或留白）。
预期结果（自查用）
  • 全部 8 页配色统一（标题、强调色一致），字体为微软雅黑。
  • 第 1 页为整幅图片背景，无白边（拉伸填充）；第 2 页为浅蓝到深蓝的渐变；第 3 页为浅灰蓝纯色且无母版花纹；第 8 页为平铺纹理。
  • 第 3 页「隐藏背景图形」勾选后，母版上的装饰元素消失，其余页仍保留。
  • 重置背景后第 1 页回到主题背景，其他页不受影响。
  • 「应用到全部」会把当前背景套到所有页——这正是第 3 小题要先全部应用、再单页调整的原因。

P-03

母版改造：一次改字体、加 logo、补页码

★★☆☆ · 28 分钟 · 35 分
操作目标

掌握幻灯片母版的层级关系与占位符修改，这是「全文统一」的唯一正确做法，也是演示题必考项。

具体要求
  1. 进入幻灯片母版视图，在最上层的母版中把「标题」占位符设为微软雅黑、40 号、加粗、深蓝 RGB(31,56,100)，正文占位符设为微软雅黑、24 号、行距 1.3。
  2. 在母版右上角插入 logo 图片（宽 2.5 厘米），位置距上边 0.8 厘米、距右边 1.0 厘米。
  3. 在母版底部居中插入幻灯片编号占位符（插入 → 幻灯片编号），字号 12、灰色；再插入日期占位符，设为自动更新格式。
  4. 为「标题和内容」版式单独调整：把正文占位符的下边界上移 1 厘米，为底部页码留出空间（验证版式可以独立于母版修改）。
  5. 新建一个自定义版式「两栏图文」：左侧图片占位符、右侧文本占位符；重命名后关闭母版视图。
  6. 用新建的「两栏图文」版式插入第 9 页，并在两个占位符中分别插入图片与文字，验证占位符可用。
  7. 回到母版，把标题字号从 40 改为 36，关闭母版视图后确认所有页面标题同步变化。
预期结果（自查用）
  • 所有页面标题为微软雅黑 40 号加粗深蓝，正文为微软雅黑 24 号、行距 1.3（改母版前逐页设置的格式被覆盖）。
  • 每页右上角有 logo，位置一致、大小一致；只在母版上存在一份。
  • 除第 1 页（标题版式默认无编号）外，其余页底部显示页码与日期。
  • 第 9 页使用「两栏图文」版式，左图右文，占位符提示文字可被替换。
  • 把母版标题改为 36 号后，8 页标题全部变为 36 号，无需逐页修改。
