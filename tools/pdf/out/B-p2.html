使用说明

电子表格操作题同样占 30 分，但它的评分逻辑与文字题完全不同：文字题看「格式是否精确」，表格题看「结果是否正确」。一个 VLOOKUP 少写一个 $，填充下去就是一片 #N/A，对应的 8—10 分全部丢失——表格题是最容易「一步错、步步错」的模块。

本部分把第 4—6 课时的 12 个小节重组为四条能力线：① 表格的形（工作表、格式、打印）② 计算的骨（引用、函数、数组）③ 分析的手（排序、筛选、汇总、模拟）④ 呈现的脸（图表、透视表）。函数按「统计 → 查找 → 文本日期 → 多条件数组」的顺序递进，避免一上来就背 50 个函数名。

编号规则与第一部分一致：知识点 S01—S35，练习 S-01—S-14。所有练习给出的数据都可直接录入，不需要外部素材文件。

1.1.1

工作簿、工作表与打印输出

考纲 三·1
核心内容
  • 工作簿与工作表：重命名（双击标签）、插入、删除、移动或复制（按住 Ctrl 拖动＝复制）、标签颜色
  • 工作组：按住 Ctrl 选多张不连续表、Shift 选连续表，可批量输入与批量设格式（成组后标题栏显示「工作组」）
  • 行高列宽：精确输入厘米／像素值、自动调整（双击列边界）、平均分布各列
  • 冻结窗格：冻结首行／首列／冻结拆分窗格（以当前单元格左上为界），用于长表浏览
  • 打印区域（页面布局 → 打印区域 → 设置）、打印标题（顶端标题行 $1:$1、左端标题列 $A:$A）
  • 页面设置：纸张 A4、方向、页边距、缩放「调整为 1 页宽」、居中方式（水平／垂直）
  • 页眉页脚：页码 &P、总页数 &N、文件名 &F、日期 &D，位置与格式可自定义
关键操作路径
  • 页面布局 → 打印标题 → 顶端标题行（点右侧折叠按钮选第 1 行）
  • 页面布局 → 页边距 → 自定义 → 缩放「调整为 1 页宽 1 页高」
  • 视图 → 冻结窗格 → 冻结首行

1.1.2

数据输入与单元格格式化

考纲 三·2
核心内容
  • 序列填充：填充柄拖动、Ctrl+拖动切换「复制／序列」、填充序列对话框（等差／等比／日期／自动填充）
  • 自定义序列：文件 → 选项 → 自定义序列，导入「部门」顺序后可直接拖动生成
  • 日期与时间本质是数值：日期格式 yyyy年m月d日，时间 hh:mm:ss；输入 2026-3-5 与 2026/3/5 都可识别
  • 自定义数字格式：¥#,##0.00（货币）、0.00%（百分比）、#,##0（千分位）、000000（前导零）、[红色]-0.00（条件格式）
  • 文本型数字：先设「文本」格式再输入，或输入前加英文单引号；学号、身份证号、手机号必须如此
  • 数据有效性（数据验证）：序列、整数、小数、日期、自定义公式；输入信息与出错警告三选项卡
  • 条件格式：突出显示规则、数据条、色阶、图标集、新建规则（公式）；管理规则可改适用范围与优先级
  • 选择性粘贴：数值、格式、列宽、转置、运算（加／减／乘／除）；格式刷单击一次、双击连续
关键操作路径
  • 开始 → 数字格式下拉 → 其他数字格式 → 自定义
  • 数据 → 数据有效性 → 序列（来源用英文逗号分隔）
  • 开始 → 条件格式 → 数据条 / 新建规则

1.1.3

单元格引用与公式基础

考纲 三·4
核心内容
  • 相对引用 A1：填充时行列都变；绝对引用 $A$1：怎么填都不变；混合引用 $A1（列锁定）、A$1（行锁定）
  • 跨表引用：表名!A1；表名含空格或数字开头时写 '2026年数据'!A1
  • 三维引用：=SUM(1月:3月!B2) 汇总多张同结构表的同一单元格
  • 定义名称：公式 → 名称管理器；名称可用于公式与数据有效性来源，比单元格地址可读
  • 运算符优先级：冒号、空格（交集）、逗号（并集）→ 负号 → % → ^ → * / → + - → & → 比较运算符
  • 错误值：#DIV/0!（除零）、#VALUE!（类型错）、#REF!（引用失效）、#NAME?（函数名错）、#N/A（查不到）、#NUM!（数值越界）
  • 公式审核：追踪引用单元格／从属单元格、显示公式（Ctrl+`）、公式求值（逐步看中间结果）
关键操作路径
  • 公式 → 名称管理器 → 新建
  • 公式 → 追踪引用单元格 / 公式求值
  • 编辑栏选中部分公式按 F9 可临时求值（Esc 撤销）

易错
  • $ 只锁它前面的那一项：$A1 锁列不锁行，A$1 锁行不锁列，背反了整张表都错。
  • 在公式里手打中文引号「」会得到 #NAME?，函数参数必须用英文半角符号。
1.1.4

数学统计函数与逻辑函数

考纲 三·4
核心内容
  • 基础统计：SUM、AVERAGE、MAX、MIN、COUNT（只数数字）、COUNTA（数非空）、COUNTBLANK（数空白）、MEDIAN
  • 取整四兄弟：ROUND（四舍五入）、ROUNDUP（向上）、ROUNDDOWN（向下）、INT（向下取整到整数）、TRUNC（截断）
  • MOD 取余：MOD(n,2)=0 判偶数；ABS 绝对值；SUMIF／COUNTIF／AVERAGEIF 单条件统计
  • IF 单条件：=IF(条件, 真值, 假值)；嵌套三级以上建议改用 IFS（新版）或 VLOOKUP 区间查表
  • AND／OR／NOT：AND 全真为真、OR 一真为真；与 IF 组合时注意括号层级
  • IFERROR(value, 出错时显示的值)：包裹查找与除法，避免满屏错误值
  • 函数嵌套技巧：先在记事本里把括号配对写完，再粘进编辑栏；Ctrl+Shift+Enter 生成数组公式（旧版）
关键操作路径
  • 公式 → 插入函数（fx）→ 选择类别「数学与三角函数」
  • 编辑栏左侧 fx 按钮可查看每个参数的说明与实时结果
  • 公式 → 根据所选内容创建（批量定义名称）

易错
  • COUNT 只数数值，A 列全是文本型数字时结果为 0——这时要用 COUNTA 或先转数值。

1.2.1

查找与引用函数

考纲 三·4
核心内容
  • VLOOKUP(查找值, 查找区域, 返回列号, 匹配方式)：第 4 参数 0/FALSE 为精确，1/TRUE 为近似（要求首列升序）
  • 查找区域必须绝对引用（$A$2:$D$100），否则向下填充时区域会整体下滑
  • 返回列号从查找区域的第一列开始数，不是从 A 列开始数
  • IFERROR(VLOOKUP(...), "未找到")：把 #N/A 变成可读文字，是评分点也是「专业度」分
  • INDEX(返回区域, MATCH(查找值, 查找列, 0))：可向左查（VLOOKUP 只能向右）
  • HLOOKUP 横向查找；INDIRECT("表名!A1") 用文本拼引用，可做动态表名
  • OFFSET(基准, 行偏移, 列偏移, 高, 宽) 构造动态区域，常与 SUM／COUNTA 组合做累计求和
关键操作路径
  • 公式 → 插入函数 → 查找与引用 → VLOOKUP
  • 选取区域后按 F4 快速加 $（一次绝对、两次锁行、三次锁列）
  • 公式 → 追踪引用单元格（排查 #N/A 时最有效）

易错
  • 近似匹配忘排序会得到「看起来随机」的结果，这是最隐蔽的错误。
  • 查不到数据显示 #N/A 而不是 0，若题目要求「未找到」必须用 IFERROR 包一层。
1.2.2

文本函数与日期时间函数

考纲 三·4
核心内容
  • 截取三件套：LEFT(文本, n)、RIGHT(文本, n)、MID(文本, 起始位置, n)
  • LEN 长度、FIND（区分大小写）／SEARCH（不区分）、SUBSTITUTE（按内容替换）／REPLACE（按位置替换）
  • TEXT(值, "0000-00-00")：把数值或日期转成指定格式的文本
  • 连接：& 运算符、CONCAT、TEXTJOIN(分隔符, 忽略空, 区域)
  • 身份证：生日 =MID(证号,7,8)；性别 =IF(MOD(MID(证号,17,1),2),"男","女")；年龄 =DATEDIF(生日,TODAY(),"y")
  • 日期函数：TODAY()、NOW()、YEAR／MONTH／DAY、DATE(年,月,日)
  • DATEDIF(开始, 结束, "y"／"m"／"d"／"ym"／"md")：算整年、整月、零头月、零头日
  • EDATE(日期, 月数) 算 N 个月后；EOMONTH(日期, 0) 算当月月末；WORKDAY／NETWORKDAYS 算工作日
关键操作路径
  • 公式 → 插入函数 → 文本 / 日期与时间
  • 「公式 → 日期和时间 → DATEDIF」不在函数列表里，需手输函数名
  • 编辑栏中选中 MID(...) 按 F9 可看到截取结果，便于调试

1.2.3

数组公式与多条件统计

考纲 三·4
核心内容
  • SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2, …)：求和区域在最前，与 SUMIF 相反
  • COUNTIFS／AVERAGEIFS：参数成对出现，所有区域必须同尺寸
  • SUMPRODUCT((条件1)*(条件2)*求和区域)：数组相乘，不需要三键，也不受「区域同尺寸」以外的限制
  • 数组公式：输入后按 Ctrl+Shift+Enter，公式外层出现 {}（新版会自动溢出，不必三键）
  • 去重计数：SUMPRODUCT(1/COUNTIF(区域, 区域))；条件是「非空」时加 (区域<>"")
  • 排名与分位：RANK.EQ(值, 区域, 0)、LARGE／SMALL(区域, k)、MEDIAN、PERCENTILE(区域, 0.9)
  • 分段统计：COUNTIFS(区域, ">=60", 区域, "<70")，区间必须不重叠，否则重复计数
关键操作路径
  • 公式 → 插入函数 → 数学与三角函数 → SUMIFS / SUMPRODUCT
  • 数组公式输入后按 Ctrl+Shift+Enter（编辑栏显示 {}）
  • 公式 → 计算选项 → 手动／自动（大数据量时的提速开关）

易错
  • SUMIFS 的第一个参数是求和区域，SUMIF 的第一个参数是条件区域——两者顺序相反，考场最常见的低级错误。
  • 分段统计的区间端点重复（>=60 与 <=70）会把 70 分算两次。

数据排序与筛选

考纲 三·3
核心内容
  • 排序三要素：主要关键字、次要关键字、第三关键字；勾选「数据包含标题」可保留表头
  • 自定义序列排序：文件 → 选项 → 自定义序列，录入「经理、主管、专员」后即可按此顺序排
  • 按颜色排序：按单元格颜色／字体颜色／条件格式图标，次序可自定义
  • 自动筛选：文本筛选（包含／开头是）、数字筛选（大于／前 10 项）、日期筛选、按颜色筛选
  • 高级筛选：条件区域必须含列标题；同一行是「与」，不同行是「或」
  • 高级筛选的三个去向：在原有区域显示、将结果复制到其他位置、筛选不重复的记录
  • 排序与筛选会改变行的相对位置，公式中的相对引用可能错位，建议先做公式再排序（或改用绝对引用）
关键操作路径
  • 数据 → 排序 → 自定义排序（添加条件）
  • 数据 → 筛选 → 高级筛选 → 列表区域 / 条件区域 / 复制到
  • 数据 → 排序 → 选项 → 自定义排序次序

易错

  • 数据透视表是否已刷新；值显示方式与数字格式是否符合要求
  • 图表是否用了次坐标轴；数据标签是值还是百分比
  • 打印区域、顶端标题行、1 页宽缩放是否都已设置并预览过
  • 工作表是否按要求保护或加密；保护前是否解锁了需要输入的单元格
  • 所有数值结果是否与「预期结果」逐项核对过（不是「看起来差不多」）
