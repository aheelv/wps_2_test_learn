文字文档操作题在 100 分试卷中占 30 分，是三大操作题里分值最高、评分点最密的一块。它不考「会不会打字」，考的是参数是否精确：页边距 2.54 还是 2.5、外框是 1.5 磅双线还是三线、页码是域还是手打——每一个数字都可能是一个 2 分采分点。

本部分把第 1—3 次课的 12 个小节重新组织为四个层次：基础格式 → 对象编辑 → 长文档结构 → 协作与输出。前三章给出「学什么」和「考什么」，第四章给出「怎么练」——14 道练习从 20 分钟的单点题，递进到 50 分钟的全真综合题。

1.1　第 1 次课 · 从新建到保存：文档的出生与落盘

4 小节 · 16 道配套例题30 分对应考纲 二·1 · 二·2 · 二·5（入门部分）
学完这次课，你要能做到
  • 能在 3 分钟内完成「新建 → 录入 → 页面设置 → 保存 → 导出 PDF」的完整闭环，并说清 .docx 与 .pdf 的差别；
  • 能准确设置字体、字号、字符间距、对齐、缩进、行距、段前段后，理解「字号磅值」与「字符缩进」的换算；

1.1.1

新建、录入、选定与保存

考纲 二·1
核心内容
  • 新建（Ctrl+N）／另存为（F12）／自动保存与恢复；.docx 与 .doc、.pdf、.wps 的区别
  • 三种换行：段落标记 Enter、手动换行 Shift+Enter、分页符 Ctrl+Enter——段落的划分只认 Enter
  • 录入规范：中文用全角标点，英文与数字用半角；段首不敲空格，缩进交给段落设置
  • 选定：双击选词、三击选段、Ctrl 选不连续区域、Shift 扩展选区、Alt 纵向选择
  • 撤销 Ctrl+Z 与恢复 Ctrl+Y；格式刷单击用一次、双击连续用
关键操作路径
  • 文件 → 新建 / 另存为（F12 直接弹另存为）
  • 开始 → 显示/隐藏编辑标记（¶），用来检查空格与空行
  • 开始 → 格式刷（双击锁定，Esc 退出）

下图把本节「关键操作路径」标在真实界面上：橙色编号与路径同序，图例给出按钮全名，照数字依次点即可。

易错
  • 用 Shift+Enter 换行后设「首行缩进」，会出现整段只缩进第一行的假象——那其实是两个段落。
  • 段首敲 4 个空格冒充缩进，一旦改字号就全乱，评分按「段落缩进值」判定，直接不给分。
1.1.2

字符格式与段落格式

考纲 二·2
核心内容
  • 字体对话框三件套：字体（中文字体／西文字体分开设）、字符间距（加宽／紧缩／磅值）、文字效果
  • 字号对照：初号 42、小初 36、一号 26、小一 24、二号 22、小二 18、三号 16、小三 15、四号 14、小四 12、五号 10.5、小五 9（单位：磅）
  • 段落六项：对齐、左缩进／右缩进、特殊格式（首行缩进／悬挂缩进）、段前、段后、行距（单倍／1.5 倍／固定值／多倍）
  • 「段前 0.5 行」与「段前 6 磅」不等价：行距为固定值时，行单位会失效，必须改用磅
  • 项目符号与自动编号：级别、起始编号、编号之后的分隔符（制表符／空格）
  • 段落边框与底纹：应用于「段落」还是「文字」，效果完全不同
关键操作路径
  • 开始 → 段落对话框（右下角小箭头）→ 缩进和间距
  • 开始 → 边框下拉 → 边框和底纹 → 应用于段落
  • 开始 → 编号下拉 → 定义新编号格式

下图把本节「关键操作路径」标在真实界面上：橙色编号与路径同序，图例给出按钮全名，照数字依次点即可。

易错
  • 「首行缩进 2 字符」在字号变化后仍按字符算，而「0.74 厘米」是死值——题目说 2 字符就选字符。
  • 全文选中后设行距，会把标题的段前段后一起改掉；正确做法是先设正文样式，再单独调标题。
1.1.3

样式、主题、查找替换与页面装饰

考纲 二·2
核心内容
  • 样式：内置样式（标题 1—9、正文、题注）／新建样式／修改样式／样式集；修改样式可一次改全文
  • 导航窗格（视图 → 导航窗格）按大纲级别列出标题，是检查「标题是否真的套了样式」的唯一可靠方法
  • 查找替换三进阶：纯文本替换、格式替换（查找格式→替换格式）、特殊字符（^p 段落标记、^t 制表符、^m 手动换行）、通配符（? * [] {} <>）
  • 页面布局：纸张（A4 = 21 × 29.7 厘米）、页边距（默认上下 2.54、左右 3.17）、方向、装订线、文档网格
  • 分栏（等宽／偏左偏右、栏间加分隔线）、首字下沉（下沉行数、距正文距离）
  • 页面装饰：水印（文字／图片、斜式／水平）、页面边框（线型／艺术型）、页面颜色
关键操作路径
  • 开始 → 样式窗格右下角箭头 → 新建样式 / 修改
  • 开始 → 查找 → 高级查找 → 更多 → 使用通配符
  • 页面布局 → 分栏 / 水印 / 页面边框

下图把本节「关键操作路径」标在真实界面上：橙色编号与路径同序，图例给出按钮全名，照数字依次点即可。

易错
  • 手工把标题设成「黑体二号加粗」，导航窗格里却不显示——因为没套样式，自动目录也抓不到。
  • 替换时勾了「使用通配符」，^p 就失效了（通配符模式下 ^p 不表示段落标记），要分两次替换。
1.1.4

长文档五件套与综合大题

考纲 二·5
核心内容
  • 分节符四种：下一页／连续／奇数页／偶数页；节是「页面设置 + 页眉页脚 + 页码」的作用单位
  • 页眉页脚：双击页边区域进入；首页不同、奇偶页不同两个复选框；页眉横线用「段落边框」而非下划线
  • 页码：插入 → 页码 → 位置／格式／起始页码；页码必须是「域」，手打的数字不随页数变化
  • 表格：插入时直接指定行列；「文本转换成表格」按制表符／逗号／段落标记分隔
  • 图片：嵌入型不能设环绕间距，必须改成四周型／紧密型后才能精确控制 0.5 厘米
  • 自动目录：前提是标题套了标题样式；插入 → 目录 → 自定义目录 → 显示级别 3 → 更新整个目录
关键操作路径
  • 页面布局 → 分隔符 → 分节符（下一页）
  • 插入 → 页眉和页脚 → 勾选首页不同 / 奇偶页不同
  • 引用 → 目录 → 自定义目录 → 修改 → 更新整个目录

易错
  • 分节后直接改第 2 节页码，第 1、3 节跟着变——因为「同前节」还连着，必须先点掉。
  • 目录生成后手动改了文字，再次「更新目录」全部丢失；目录内容只能通过改标题来改。

这次课的关键不是「会点按钮」，而是建立三条肌肉记忆：段首不敲空格、格式交给样式、页码用域。

16 道配套例题中，第 2 题与第 3 题是分水岭：能独立做完「页眉页脚 + 自动目录」，后面的 30 分题基本不会低于 22 分。

1.2.1

页眉页脚与页码进阶

考纲 二·5
核心内容
  • 三个独立的页眉页脚区域：首页、奇数页、偶数页——勾选复选框后要分别填写，只填一个会导致另一种页面全空
  • 「同前节」（链接到前一条页眉）：默认开启，断开后本节才能有独立的页眉页脚与页码格式
  • 页码格式：编号格式（1,2,3／I,II,III／a,b,c／第 X 页）、起始页码、续前节
  • 页码域 Page 与总页数域 NumPages；分节后「共 Y 页」要改用 SectionPages 才是本节页数
  • 页眉横线 = 段落的下边框，可设线型与磅值；页脚位置可用「页脚底端距离」精确控制
  • StyleRef 域：让页眉自动引用当前页所属「标题 1」的文字，是标书、论文的标配
关键操作路径
  • 插入 → 页眉和页脚 → 勾选首页不同 / 奇偶页不同
  • 页眉页脚选项卡 → 同前节（点亮即链接，点灭即断开）
  • 插入 → 域 → 类别「链接和引用」→ StyleRef → 选择标题 1

下图把本节「关键操作路径」标在真实界面上：橙色编号与路径同序，图例给出按钮全名，照数字依次点即可。

易错
  • 先填内容再勾「奇偶页不同」，原内容会整体挪到奇数页，必须重新检查偶数页。
  • 在页脚手打「第 1 页 共 4 页」，删掉一页后数字不动，评分点直接判错。
1.2.2

表格的制作与编辑

考纲 二·3
核心内容
  • 插入表格三种方式：对话框指定行列、绘制表格、文本转换成表格（分隔符选制表符）
  • 合并／拆分单元格、拆分表格（Ctrl+Shift+Enter）；单元格九宫格对齐（靠上居中／正中／靠下）
  • 行高列宽：表格属性里填厘米；「平均分布各列」用于消除手工拖拽的误差
  • 表格整体居中用「表格属性 → 对齐方式 → 居中」，用「开始」的居中按钮只是段落居中
  • 边框：先选线型线宽，再在预览图上点位置；外框与内线要分两次设置
  • 底纹：按 RGB 值取色（其他颜色 → 自定义），不要挑「看起来差不多」的主题色
  • 重复标题行（选中首行 → 表格工具 → 重复标题行）、允许／禁止跨页断行
  • 表格公式：=SUM(LEFT)、=AVERAGE(ABOVE)、=ROUND(AVERAGE(B2:E2),1)、=IF(F2>=90,"优秀","合格")；F9 更新域
关键操作路径
  • 插入 → 表格 → 插入表格（输入列数行数）
  • 表格工具 → 表格属性 → 行／列（指定厘米）
  • 表格工具 → 边框和底纹 → 自定义（线型 / 宽度 / 预览点选）

交卷前的 5 分钟决定 3—5 分。本章的四张表建议打印出来放在手边：自查清单（逐项打勾）、评分总表（自评记录）、快捷键速查、三周练习路径。

先读这一段：本册所有参数以 WPS Office 教育考试专用版（Windows 10）为准，个人版菜单名称可能略有差异，按功能名称定位即可；文件命名一律为「学号-姓名-练习编号」，未按要求命名按 0 分处理。

5.1　交卷自查清单

做完任何一道题，都按这份清单从头念一遍。清单里每一条都对应过真实失分。

  • 文件名、保存位置、扩展名是否与题目要求完全一致（含连字符与编号）
  • 页边距是否为 2.54／3.17 厘米，纸张是否为 A4
  • 标题是否真的套用了「标题 1／2／3」样式（看导航窗格能否列出）
  • 正文字体、字号、行距、首行缩进是否落在「样式」里而不是逐段手设
  • 页码是域还是手打？分节后每节的「同前节」是否都已断开
  • 首页不同、奇偶页不同两个复选框是否都按题目要求勾选
  • 页眉横线是段落边框还是下划线
  • 表格列宽是否为厘米数值；表头是否已设「重复标题行」
  • 表格是「表格属性居中」还是「段落居中」
  • 图片环绕方式是否已从嵌入型改掉；尺寸是否为厘米值
  • 目录生成后是否按过「更新整个目录」；题注编号是否含章节号
  • 公式是否为公式对象；编号是否用右对齐制表位
  • 修订是否已按要求接受／拒绝；文档是否已加密或标记最终状态
  • 是否输出了题目要求的 PDF 副本（如需）

5.3　快捷键与操作速查

考场用快捷键不是为了快，是为了少找菜单——找不到菜单时最容易慌。

Ctrl+N / Ctrl+S / F12新建 / 保存 / 另存为
Ctrl+Enter插入分页符
Ctrl+Shift+Enter拆分表格（光标在表格中时）
Alt+Shift+P / Alt+Shift+N插入页码域 / 总页数域
F9 / Alt+F9 / Ctrl+F9更新域 / 显示域代码 / 插入空域
Ctrl+Alt+F / Ctrl+Alt+D插入脚注 / 插入尾注
Ctrl+Shift+E开启或关闭修订
Ctrl+G / Ctrl+Shift+G组合 / 取消组合
Alt+拖动 / Ctrl+拖动纵向选择文本 / 复制拖动
Shift+F5回到上次编辑位置
