# 大连财经学院 · 计算机国家二级考试（WPS 类）培训资料

**主办：** 大连财经学院「计算机国家二级考试（WPS 类）」课程组
**性质：** 校内教学辅助资料 · **非官方考试网站**

> ⚠ **重要声明**
> 本网站是**大连财经学院校内教学辅助资料**，**不是**官方考试网站，与教育部教育考试院及任何考试机构**无隶属或代理关系**。
> 本站**不提供、不代理**考试报名、缴费、准考证打印、成绩查询、证书办理等任何考试业务；**不收集**身份证号、手机号、银行卡等任何个人信息；**无**广告、付费课程与商业推广。
> 考试政策、报名时间、成绩发布等信息，请以**中国教育考试网**（<https://ncre.neea.edu.cn>）当年公告为准。

依据《全国计算机等级考试（NCRE）二级 WPS Office 高级应用与设计考试大纲（2025 年版）》与《二级公共基础知识考试大纲（2025 年版）》编写的校内教学资料包：**11 次课 · 44 课时 · 5 大模块**，课时按考试分值配置，以帮助学生通过考试为第一原则。

**在线访问：** <https://aheelv.github.io/wps_2_test_learn/>

## 考试说明

| 项目 | 说明 |
| --- | --- |
| 科目 | 二级 WPS Office 高级应用与设计（科目代码 67） |
| 方式 | 上机考试，120 分钟，满分 100 分，60 分合格 |
| 题型 | 单项选择 20 分（含公共基础 10 分）· 文字文档操作题 30 分 · 电子表格操作题 30 分 · 演示文稿操作题 20 分 |

## 课时按分值配置

| 模块 | 内容 | 课时 | 对应分值 |
| --- | --- | --- | --- |
| M1 | 公共基础与 WPS 综合应用基础 | 8 | 单选 20 分 |
| M2 | WPS 处理文字文档 | 12 | 文字操作题 30 分 |
| M3 | WPS 处理电子表格 | 12 | 表格操作题 30 分 |
| M4 | WPS 设计演示文稿 | 8 | 演示操作题 20 分 |
| M5 | 全真模拟与考前冲刺 | 4 | 综合提分（含完整模拟卷） |

## 用户权限系统

学生 / 教师 / 管理员三级角色，按权限控制功能访问：

| 角色 | 主要权限 |
| --- | --- |
| 学生 | 学习资料浏览、模拟考试、查看班级群、个人资料 |
| 教师 | 学生权限 + 建群与群二维码管理、发布通知、数据导出 |
| 管理员 | 全部权限 + 用户与角色管理、邀请码、系统设置 |

**默认演示账号：** `admin / admin123`（管理员）、`teacher / teacher123`（教师）、`student / student123`（学生）。

> ⚠ **数据存储说明**：本站为 GitHub Pages 纯静态站点，**没有服务端**。用户、权限、班级群资料与上传的群二维码图片全部保存在**访问者本人的浏览器本地存储**中，不会上传到任何服务器，也无法跨设备共享。如需跨设备同步，请在用户中心**导出数据包（JSON）**后分发导入。本地模拟的权限仅用于校内教学演示与轻量管控，不等同于服务端级安全机制，请勿在其中保存敏感信息或复用重要密码。

> 微信群需在微信客户端内创建，微信官方未开放个人微信建群接口；本站仅用于**登记群信息并发布群二维码**，不代建群、不介入微信账号体系。

## 本地查看

直接双击 `index.html` 即可浏览；或启动本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。
