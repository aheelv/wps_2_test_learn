# 大连财经学院 · 计算机国家二级考试（WPS 类）培训资料

**主办：** 大连财经学院「计算机国家二级考试（WPS 类）」课程组
**性质：** 校内教学辅助资料 · **非官方考试网站**

> ⚠ **重要声明**
> 本网站是**大连财经学院校内教学辅助资料**，**不是**官方考试网站，与教育部教育考试院及任何考试机构**无隶属或代理关系**。
> 本站**不提供、不代理**考试报名、缴费、准考证打印、成绩查询、证书办理等任何考试业务；**不收集**身份证号、手机号、银行卡等任何个人信息；**无**广告、付费课程与商业推广。
> 考试政策、报名时间、成绩发布等信息，请以**中国教育考试网**（<https://ncre.neea.edu.cn>）当年公告为准。

依据《全国计算机等级考试（NCRE）二级 WPS Office 高级应用与设计考试大纲（2025 年版）》与《二级公共基础知识考试大纲（2025 年版）》编写的校内教学资料包：**11 次课 · 44 课时 · 5 大模块**，课时按考试分值配置，以帮助学生通过考试为第一原则。

**在线访问：** <https://aheelv.github.io/wps_2_test_learn/>

## 两大核心模块

整站按「直接对应考试得分的内容优先」组织，首页与主导航只把这两块放在最前面：

| 核心模块 | 入口 | 规模 | 对应分值 |
| --- | --- | --- | --- |
| 实操训练 | `实操训练.html` + 8 个课页 | 8 次课 · 32 小节 · 72 道操作题 | 操作题 80 分 |

## 练习素材与完成比对

- 每题一个独立素材包，命名 `练习N-M-题目短名.zip`，包内只放**起始**文字、原始数据与必要附件，答案动作（格式、公式、图表、动画、修订、目录、题注等）均不预置。
- 完成比对产物与起始素材**分开存放**，避免把答案打进下载包：每题一套 `完成比对文档.html` + 解题结果文件 + `操作示意.svg`，网页素材块内提供统一的「完成比对文档」入口。
- 全部数据为自拟教学数据，不含真实个人信息。

## 理论考试归属

理论考试与实操训练**并列为一级核心模块**，主导航同级可达。两级结构：栏目主页负责导学与大纲对应，离线题库负责刷题。`11-6/` 仅保留源数据与构建脚本，不在站内暴露入口，避免同名内容两处可点。

理论选择题按 2025 大纲**包含** PDF 处理、WPS 在线办公概念、文档上云与共享协作等概念考点；而 72 道操作题严格限定在**离线 WPS Office 教育考试专用版**可用功能内，不调用云端、AI、插件、宏或需联网验证的动作。两者互不越界。

## 考试环境与版本口径

- 软件环境统一写 `WPS Office 教育考试专用版`（2025 年版考试大纲指定考试环境），不绑定具体小版本号、不混用个人版或旧版年份。
- 组件术语统一为 `WPS 文字` / `WPS 表格` / `WPS 演示`；功能入口按该版本现行功能区命名。
- 全站范围审计结论：230 个文件 0 处版本 / 表述缺陷，72 道操作题 0 处越界，操作类知识点 48 / 48，2025 大纲条目 28 / 28，素材与全链路交付校验 33 / 33，站内 1497 条本地引用 0 条失效。

## 用户权限系统

学生 / 教师 / 管理员三级角色，按权限控制功能访问：

| 角色 | 主要权限 |
| --- | --- |
| 学生 | 学习资料浏览、模拟考试、查看班级群、个人资料 |
| 教师 | 学生权限 + 建群与群二维码管理、发布通知、数据导出 |
| 管理员 | 全部权限 + 用户与角色管理、邀请码、系统设置 |

**课程内容、实操训练、理论考试免登录即可学习**；模拟考试、用户中心、班级群按需保留账号门禁。

**默认演示账号：** `admin / admin123`（管理员）、`teacher / teacher123`（教师）、`student / student123`（学生）。

> ⚠ **数据存储说明**：本站为 GitHub Pages 纯静态站点，**没有服务端**。用户、权限、班级群资料与上传的群二维码图片全部保存在**访问者本人的浏览器本地存储**中，不会上传到任何服务器，也无法跨设备共享。如需跨设备同步，请在用户中心**导出数据包（JSON）**后分发导入。本地模拟的权限仅用于校内教学演示与轻量管控，不等同于服务端级安全机制，请勿在其中保存敏感信息或复用重要密码。

> 微信群需在微信客户端内创建，微信官方未开放个人微信建群接口；本站仅用于**登记群信息并发布群二维码**，不代建群、不介入微信账号体系。

## 本地查看

直接双击 `index.html` 即可浏览；或启动本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000/>。

`.gitignore` 明确排除：密钥与凭据文件（`.env` / `*.pem` / `*.key` / `.git-credentials` 等）、依赖目录（`node_modules/` / `.venv/`）、Python 与工具缓存（`__pycache__/` / `*.pyc` / `.pytest_cache/`）、构建中间产物（`_build/` / `tools/pdf/out/` / `*.log` / `*.bak`）、本地临时文件（`.tmp_*` / `tools/_shots/` / `_wps_publish_tmp/`）、系统文件，以及本地会话记忆 `.workbuddy/`。

## 本地重建与校验

脚本均为幂等，按以下顺序可重建整套站点与交付结论：

```bash
python tools/material/fix_scope.py       # 例 8-3 表述修订 + 下游同步
python tools/site_theory.py              # 理论考试栏目与离线题库
python tools/site_home.py                # 首页核心模块优先
python tools/site_nav.py                 # 全站导航 / 内容配置页 / 链接校验
python tools/site_audit.py --report      # 全站范围与版本审计
python tools/syllabus_map.py             # 2025 大纲 28 条覆盖矩阵
python tools/material/verify.py          # 33 项素材与全链路交付校验
python tools/site_report.py              # 核查与重构报告
```
